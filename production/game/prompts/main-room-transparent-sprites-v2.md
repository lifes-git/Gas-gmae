# 메인 탐색 투명 스프라이트 v2

작성일: 2026-09-02  
도구: OpenAI built-in ImageGen  
용도: 웹게임 프로토타입 메인 탐색 장면

## 공통 기준

- 기존 메인 배경과 같은 따뜻하고 정돈된 한국 가정집용 2D 게임 일러스트 스타일
- 굵은 외곽선이나 과장된 3D 렌더링을 피하고 부드러운 명암과 약한 접지 그림자 사용
- 사물 이외 영역은 실제 알파 투명 배경
- 글자, UI, 발광 원, 손 커서, 체크 표시를 이미지에 포함하지 않음
- 1280×720 고정 월드의 HTML hotspot 안에 배치할 독립 스프라이트

## 생성 에셋

1. 열림 상태 가스 중간밸브: 회색 세로 배관과 노란 세로 손잡이, 정면에 가까운 시점.
2. 잠김 상태 가스 중간밸브: 1번과 동일한 본체·캔버스·조명, 노란 손잡이만 가로 방향. 최종 방향은 안전 검수 전 프로토타입.
3. 접힌 민트색 주방 수건: 깨끗하고 단순한 형태, 화기 가까이 놓인 위험요소로 인식 가능한 크기.
4. 다 쓴 빨간 부탄캔: 옆으로 누운 상태, 짧고 부드러운 접지 그림자.

## 후처리

- `production/game/tools/prepare_main_scene_sprites.py`로 투명 여백을 정리하고 런타임 크기로 축소.
- 밸브 두 상태는 같은 228×512 캔버스를 유지해 교체 시 위치가 움직이지 않도록 함.
- 메인 탐색 배경은 기존 승인 마스터를 1280×720으로 축소한 `bg-room-clean-v2.png` 사용.

## 선택·폐기 기록

- 체크무늬가 픽셀로 포함된 초기 잠김 밸브 결과는 폐기.
- 배경 일부를 포함해 경계가 보이던 통합 배경 및 국소 상태 패치 방식은 런타임에서 폐기.
