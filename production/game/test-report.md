## 이번 테스트에서 수정된 결함

- 완료 현관문의 위치 이동 애니메이션 때문에 클릭 대상이 안정되지 않던 문제를 그림자 펄스로 변경했다.
- 재시작 뒤 해결 완료 `aria-label`이 남던 문제를 기본 라벨 저장·복원 방식으로 수정했다.
- 결과 제목이 포커스를 받을 수 있도록 `tabindex=-1`을 추가했다.
- E2E가 미션 순서와 모달 닫힘 애니메이션에 의존하던 문제를 제거했다.
- 사용자 결정에 따라 타이머 UI와 관련 상태·테스트를 제거했다.

## 아직 하지 않은 검증

- Firefox, WebKit: 현재 로컬 브라우저 바이너리 없음
- axe 자동 접근성 검사, 스크린리더, 200% 확대 수동 검사
- 실제 iOS Safari와 Android Chrome
- 성인 대리 사용자 3명 이상의 2–3분 플레이테스트 및 안전수칙 회상 조사
- 최종 이미지가 들어간 뒤 hotspot 위치, 작은 화면 가독성, 초기 전송량 회귀 테스트

위 항목은 최종 빌드 승인 조건이며 이번 프로토타입 통과로 완료 처리하지 않는다.

## 에셋 통합 회귀 — 2026-08-31

- 허브 화면을 `bg-room-day-master-v1`과 투명 밸브·수건·부탄캔 소품으로 교체했다.
- 밸브, 수건, 부탄캔 실내, 부탄캔 실외 확대 화면에 동일 스타일 배경·소품·소멍이 상태 포즈를 적용했다.
- 에셋 프리로드 후 데스크톱 전체 흐름, 키보드 전용, 390×844 모바일 터치 프로필을 다시 통과했다.
- 확대 화면 캡처: `qa/screenshots/mission-valve.png`, `mission-towel.png`, `mission-butane-indoor.png`, `mission-butane-outdoor.png`.
- 불투명 런타임 배경을 JPEG로 최적화하고 안내 캐릭터를 축소해 런타임 에셋 합계를 약 7.7MB에서 약 2.1MB로 낮췄다. 마스터 PNG는 보존했다.
- 제거한 파일은 런타임 폴더의 중복 배경 PNG 5개이며 동일한 마스터 PNG와 사용 중인 JPEG가 남아 있다.

## 스토리보드형 UI 개편 회귀 — 2026-08-31

- 사용자 인터뷰 결과에 따라 웹 대시보드형 헤더·사이드바를 16:9 장면 중심 게임 스테이지로 교체했다.
- 좌측 하단 소멍이 말풍선, 상단 장면명·진행 원, 12초 무입력 이름 힌트를 적용했다.
- 위험요소 선택 시 1.07배 이하의 완만한 줌 후 전체 미션 장면으로 전환한다. 모션 감소 설정에서는 애니메이션을 생략한다.
- 성공 후 자동 복귀 대신 `왜 안전한가요?`와 `방으로 돌아가기`를 제공한다.
- 열린 현관 배경과 외출 포즈 소멍이를 시작·완료 화면에 적용했다.
- 개편 후 Chromium 데스크톱, 키보드 전용, 390×844 모바일 터치 흐름을 다시 통과했다.

## 전체화면·직접 조작 회귀 — 2026-09-01

- 게임 외곽 여백과 프레임을 제거하고 모든 가로 뷰포트를 채우도록 변경했다.
- 전체화면 진입·종료 버튼과 지원 환경의 가로 방향 잠금 시도를 추가했다.
- 모바일 세로 390×844에서는 회전 안내가 표시되고 게임 입력이 차단된다. 844×390으로 전환하면 안내가 사라지고 게임을 완료할 수 있다.
- 밸브 회전, 수건 드래그, 부탄캔 실외 드래그, 노즐 길게 누르기 직접 조작으로 데스크톱 전체 흐름을 완료했다.
- Tab 키 감지 후 표시되는 대체 버튼만으로 키보드 전체 흐름을 완료했다.
- 직접 조작 실패 2회 시 대체 버튼을 표시하며 잘못된 드롭은 원위치로 복귀하도록 구현했다.
- Chromium 브라우저 오류와 가로 넘침 없이 전체 회귀 테스트를 통과했다.

알려진 제한: Fullscreen API와 `screen.orientation.lock()` 지원 여부는 브라우저·OS 정책에 따라 다르다. 밸브 최종 열린/잠긴 방향은 Safety Reviewer 승인 전까지 프로토타입 상태다.
