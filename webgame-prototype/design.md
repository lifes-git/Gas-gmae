# Gas Safety Webgame Prototype: UI 지침

## 2026-09-02 통합 UI 인터뷰 승인

- 확대 화면: 기존 장면을 어둡게 두고 중앙 90% 16:9 장면, 얇은 테두리와 닫기만 표시
- 안내: 확대 장면 왼쪽 아래 소멍이와 오른쪽 크림색 말풍선; 안내·오류·성공을 같은 자리에서 교체
- 조작: 점선 원과 직접 조작 우선, 키보드 입력 또는 두 번 실패 후에만 버튼 대안 노출
- HUD: 왼쪽 `안전 점검 n/3`, 오른쪽 설정 아이콘; 전체화면·효과음·진동·재시작은 설정 안으로 이동
- 소지품: 글자 없는 한 칸 아이콘 슬롯, 비었을 때 숨김, 소지 중에는 방향 배지와 현재 목적지만 활성화. 전체 안내는 `aria-label`과 소멍이 대사로 유지
- 현관: 실제 문틀 전체에 클릭 영역을 맞추고 활성 상태에만 흰 윤곽과 바깥쪽 화살표 표시. 화면 글자는 사용하지 않고 접근 가능한 이름은 유지
- 완료: 실외 배경, 소멍이 완료 말풍선, 점검한 세 행동 요약

## 2026-09-02 가로 집중 탐색 UI 승인

- 16:9 장면은 화면 안에 온전히 맞춰 중앙 정렬하고 남는 위·아래 또는 좌우 영역은 현재 장면의 블러로 채운다.
- 방 이동은 좌우 가장자리 화살표를 사용한다. 입력 영역은 고정하고 화살표 그림만 이동 방향으로 왕복한다.
- 메인 탐색과 집기 확대 화면의 원형 표시는 제거한다. 조작 가능한 소품에 흰색 실루엣 외곽선을 사용한다.
- 수건·부탄캔은 hover·focus 시 2~3도 기울이고 밸브는 회전 없이 확대만 적용한다.
- 진행 HUD와 완료 점검표는 아이콘과 짧은 문구 중심으로 축약하며 안전 설명 원문은 별도 수칙 화면에 유지한다.
- 데스크톱 미션 모달은 화면 높이 약 72% 이하로 줄이고 내부 장면의 시야 범위도 넓혀 과도한 확대를 피한다.

## 현재 적용 기준 — 2026-09-02

사용자 승인에 따라 크림색 점검 메모 기반 UI로 단계적으로 전환한다. 단일 기준은 `../production/game/design.md`의 “메모 UI 전환” 절이다. 아래 Retro Arcade 규칙은 이전 구현 기록이며 신규 작업에 적용하지 않는다.

현재 단계: 시작 화면의 메모 레이아웃 수정. 다른 화면은 아직 전환하지 않았다. 캐릭터는 자신의 그리드 열 너비를 넘지 않으며, 제목과 버튼은 종이 내부에 유지한다. 사용자 시각 검수 후 공통 버튼부터 순차 반영한다.

## 이전 기준: Retro Arcade (보관용)

이 문서는 게임 전반의 디자인 통일성을 유지하기 위한 핵심 디자인 토큰(Design Tokens)과 스타일 가이드라인을 정의합니다.

## 1. Typography (서체)
* **Main Titles (`.retro-title`):**
  * **Font:** `'Jua'`, `'Dongle'`, `'Comic Sans MS'`, sans-serif
  * **Weight:** 900 (Black)
  * **Stroke/Shadow:** 두꺼운 흰색 8방향 겹침 그림자(`text-shadow`) 사용. 계단현상 방지를 위해 최소 24-point shadow 권장.
  * **Drop Shadow:** 하단으로 향하는 짙은 그림자 적용.

## 2. Color Palette (색상)
오락실 아케이드 게임이나 동화책에서 볼 법한 팝(Pop)하고 따뜻한 원색을 사용합니다.
* **Red (Main/Alert):** `#ff4757`
* **Orange (Primary Actions):** `#ffb142`
* **Yellow (Warning/Accent):** `#fca311`
* **Green (Success/Solved):** `#1dd1a1`
* **Blue (Info/Secondary):** `#0984e3`
* **Text (Ink):** `#2f3640`
* **Modal Background (Retro):** `#ffecb3` (따뜻한 노란색 베이스)

## 3. UI Components (요소 형태)
### Buttons (`.retro-button`)
* **Shape:** 타원형 알약(Pill) 모양 (`border-radius: 999px`)
* **Border:** 매우 두꺼운 흰색 테두리 (`border: 6px solid white`)
* **Shadow:** 바깥 그림자와 안쪽 그림자(inset)를 동시 적용하여 입체적인 글로시(Glossy) 효과 연출.
* **Interaction:** Hover 시 밝기 증가(`filter: brightness(1.1)`), Active 시 아래로 눌리는 애니메이션(`transform: translateY(6px)`).

### Modals (`.retro-modal`)
* **Shape:** 둥근 모서리를 가진 박스 (`border-radius: 24px`)
* **Border:** 두꺼운 흰색 테두리 (`border: 8px solid white`)
* **Shadow:** 짙은 검은색 바깥 그림자 및 노란색 안쪽 그림자 겹침.
* **Close Button (`.retro-close`):** 모달 창 우측 상단 바깥쪽으로 튀어나오는 빨간색 원형 버튼.

### Hotspots (인게임 위험요소 타겟)
* **Pulse Target:** 빨간색 둥근 원에 굵은 흰색 테두리를 적용하여 눈에 확 띄는 오락실 과녁 느낌 연출.
* **Name Tag:** 노란색(`fca311`) 알약 모양 네임택을 타겟 하단에 상시 노출하여 직관성 강화.

## 4. In-game Background (인게임 시점)
* **View Type:** 전체 거실+주방 뷰(Panoramic View) 유지.
* **Interaction:** 방 안의 3가지 요소(가스밸브, 수건, 부탄캔)를 한 화면에서 모두 찾을 수 있도록 텐션 유지. 숨겨진 요소를 눌렀을 때만 Retro Modal 팝업 호출.

## 현재 구현 기준 — 2026-09-02

위의 Retro Arcade 항목은 보관 기록이다. 현재 구현은 `../production/game/design.md` 11절을 따른다.

- 탐색 장면은 좌우를 항상 채우고 위·아래만 중앙 크롭한다.
- 좌우 이동과 회전 안내는 코드 기반 굵은 곡선 화살표를 사용한다.
- 조작 물체는 원형 과녁 대신 흰색 실루엣 외곽선을 사용한다.
- 밸브와 야외 부탄캔은 포인터 드래그에 따라 실제로 회전하며 완료 각도를 유지한다.
- 야외 단계 표시는 제거하고 소멍이의 순차 힌트로 대체하며, 복귀는 화면 글자 없는 문 위치 아이콘으로 구성한다.
- 모든 아이콘 조작에는 한국어 접근성 이름과 키보드 대체 조작을 유지한다.

## 2026-09-03 반영

- 주방에서는 현관 입력 영역을 완전히 숨기고, 3/3 완료 시에도 거실 이동 화살표를 남긴다.
- 부탄캔 단계 표시는 없애고 소멍이 말풍선의 한 행동씩 이어지는 힌트를 사용한다.
- 야외 복귀 버튼은 배경 속 열린 현관문 위치에 맞춘다.
- 수건 완료 시 주방 바구니 안에 수건 상태를 합성한다.
- 밸브는 왼쪽 드래그와 왼쪽 방향 화살표를 사용한다.
- 배경음악은 시작 후 반복 재생하며 설정의 `음악·효과음` 토글을 따른다.
- 확대 화면 복귀는 우하단의 글자 없는 곡선 화살표로 표시하고 소멍이·말풍선은 좌하단에서 서로 겹치지 않게 배치한다.
- 조작 소품 흰색 외곽선을 약 2px 보강하고 진행 카드와 설정 버튼을 소폭 확대한다.
- 시작·완료 화면은 짙은 외곽선, 크림 내부 카드, 하늘색·라임 프레임, 코랄·하늘색 버튼을 공유하는 중앙 게임 패널로 통일한다.
