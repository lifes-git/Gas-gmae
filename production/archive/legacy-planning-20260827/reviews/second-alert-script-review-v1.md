# 《두 번째 알림은 오지 않게》 대본 단계 독립 검수 v1

검수일: 2026-08-22

## 판정

**REVISE 후 제작 가능**

대본 단계에서 치명적인 안전 오류는 발견되지 않았다. 실제 생성본이 없으므로 완성도·권리·출력·제출 심사는 아직 통과시킬 수 없다.

## 블라인드 이해 예상

설명 없이 대본만 보았을 때 예상되는 이야기:

> 요리 중 휴대전화 알림에 반응해 자리를 뜨려 하자 더 심각한 경고들이 증식한다. 주인공이 돌아와 가스불을 끄면서 위험 가능성이 사라진다.

예상 기억 행동:

> 자리를 뜨기 전 가스불을 끈다.

두 문장이 일치하므로 주제적합성의 기본 구조는 통과한다.

## 반영한 수정

1. 마지막 11초에 유사한 내레이션 두 문장이 반복되던 문제를 제거했다.
2. 0:49–0:55는 무대사 감정 해소 구간으로 확보했다.
3. 엔드카드와 내레이션을 `자리를 뜨기 전, 가스불부터 끄세요` 한 문장으로 통일했다.
4. KGS 로고는 공식 사용 허용을 확인한 경우에만 넣도록 제한했다.

## 생성 단계 차단 조건

- S01–S08에서 불꽃이 주황색·과대·복수 화구로 생성되면 폐기.
- S09A 손잡이 방향 또는 가스레인지 구조가 앞 쇼트와 다르면 폐기.
- S09B에 잔불·재점화·연기가 보이면 폐기.
- 붉은 알림 구슬이 가스·연기·불꽃으로 오인되면 그래픽 디자인 수정.
- 주인공이 실제로 주방을 떠난 뒤 오래 방치하는 장면이 만들어지면 폐기.

## 권리·증빙 차단 조건

- 실제 앱 알림음, 앱 아이콘, 휴대전화 브랜드 UI 사용 금지.
- 음악·폰트·TTS·효과음 라이선스 기록 전 최종 사용 금지.
- 실존 인물 닮은꼴 또는 유명 캐릭터·화풍이 생성되면 폐기.
- Flow 프롬프트, 후보 파일, 선택·폐기 이유, 실제 크레딧을 로그에 기록.
- KGS 로고 파일을 공식 제공받지 않았거나 사용 조건이 불명확하면 텍스트 표기만 사용.
