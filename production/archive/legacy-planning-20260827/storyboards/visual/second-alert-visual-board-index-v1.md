# 《두 번째 알림은 오지 않게》 시각 스토리보드 v1

작성일: 2026-08-23

## 읽는 순서

각 이미지는 2×2 배열이며 `좌상 → 우상 → 좌하 → 우하` 순서로 읽는다. 장면 번호·자막은 이미지 생성 오류를 피하기 위해 그림에 넣지 않았다.

| 파일 | 패널 매핑 | 상태 |
|---|---|---|
| `second-alert-board-A-S01-S04-v1.png` | S01, S02, S03, S04 | 승인 |
| `second-alert-board-B-S05-S08-v2.png` | S05, S06, S07, S08 | 승인 |
| `second-alert-board-C-S09-S11-v1.png` | S09A, S09B, S10, S11 | 조건부 승인 |

## 장면 의도

| 장면 | 시각적 판단 기준 |
|---|---|
| S01 | 휴대전화 진동과 켜진 파란 불꽃이 첫 3초 안에 함께 이해된다. |
| S02 | 조리 중 시선만 전화로 이동한다. 아직 손을 뻗지 않는다. |
| S03 | 국자를 받침에 둔 뒤 휴대전화를 집는다. |
| S04 | 한 걸음만 이동해 문턱에서 멈추며 불꽃은 화면에 남는다. |
| S05 | 인물은 문턱 우측, 레인지는 좌측에 고정되고 첫 구슬이 증식한다. |
| S06 | 구슬이 공간 전체로 퍼지지만 가스·연기처럼 보이지 않는다. |
| S07 | 커다란 구슬과 붉은 반사가 인물의 깨달음을 만든다. |
| S08 | 어깨 너머로 파란 불꽃을 다시 발견한다. |
| S09A | 사용 중인 왼쪽 화구에 대응하는 조절 손잡이를 OFF로 돌린다. |
| S09B | 파란 불꽃이 완전히 사라진 상태를 별도 클로즈업으로 확인한다. |
| S10 | 휴대전화를 뒤집어 놓고 경고 구슬이 사라진다. |
| S11 | CapCut에서 문구와 기관 표기를 넣을 수 있도록 빈 엔드카드로 유지한다. |

## 제작 레드라인

- 시각 스토리보드는 구도 기준이며 가스레인지 구조의 최종 정확성 기준은 `가스레인지-불켜짐-근접-v1.png`와 `가스레인지-불꺼짐-근접-v1.png`다.
- S09A 생성 이미지의 손잡이 주변 작은 표시 형태는 최종 영상에서 복제하지 않는다. 실제 PROP 기준으로 `왼쪽 화구 대응 손잡이 → OFF`가 명확해야 한다.
- 알림 구슬은 CapCut에서 합성한다. Flow 원본에는 구슬·문자·아이콘을 생성하지 않는다.
- 구슬은 연기, 가스, 불꽃 또는 실제 스마트폰 알림 UI처럼 묘사하지 않는다.
- S11 문구는 CapCut에서 `자리를 뜨기 전, 가스불부터 끄세요.`로 정확히 입력한다.
