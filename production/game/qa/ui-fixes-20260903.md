# 사용자 스크린샷 기반 UI 수정

- 실외 복귀 문: GameUI의 채워진 버튼 분류에서 제외. 장면 클릭 영역은 투명, 내부 화살표만 버튼 형태 유지.
- 시작·결과 제목: 두꺼운 stroke 및 여러 겹의 오프셋 그림자 제거, 단일 얕은 그림자와 900 굵기 사용. 자간 완화.
- 안전수칙: dialog를 단일 외곽 테두리로 사용하고 내부 프레임 테두리 제거, 모서리 반경 20/17px.
- 음악: 시작 전 조건 제거, 로드 시 재생 시도 및 사용자 pointer/key 입력 시 재시도. 음소거 및 문서 숨김 시 정지는 유지. 자동재생 권한은 브라우저 정책에 따름.
- 소멍이: 말풍선을 캐릭터 옆 수직 중앙에 정렬하고 꼬리도 중앙에 배치.
- 밸브 안내 화살표: 기존 좌우 반전에 상하 반전 추가, top 22% → 49%. 실제 밸브 회전 로직은 변경 없음.
- 수건·밸브: 탐색 및 확대 화면에서 투명 실루엣 기반 흰 윤곽 강화. 배경 원본 수정 없음.

검증: game.js Node 구문 검사 통과. 실제 브라우저·음악 재생·모바일 시각 검수는 미실시, 사용자 확인 필요. 최종 안전 검수 상태는 바꾸지 않음. GitHub 푸시 미실시.
