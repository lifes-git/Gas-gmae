# 프로토타입 QA 인벤토리

## 사용자에게 약속할 기능

- 한 화면에서 위험요소 3개 탐색
- 밸브, 수건, 부탄캔 미션과 안전 피드백
- 0/3~3/3 진행 상태와 완료 후 외출
- 시간 제한 없는 시작·진행·재시작
- 터치·마우스·키보드 조작과 모바일 레이아웃
- 외부 네트워크 요청 없는 정적 실행

## 필수 기능 확인

| 기능/상태 | 기능 검사 | 시각 검사 |
|---|---|---|
| 시작 화면 | 안내 확인 후 시작 | 390×844와 1440×900에서 주요 버튼 노출 |
| 밸브 오답/정답 | 오답은 미해결, 정답은 1/3 | 모달 피드백과 hotspot 체크 |
| 수건 오답/정답 | 쓰레기통 오답, 안전 보관 정답 | 꺼진 가스레인지와 이동 상태 |
| 부탄캔 안전 처리 | 실내 오답, 실외 회전·노즐·캔 수거함 클릭 순서 완료, 조기 수거함 입력 차단 | 정면형 불투명 수거함의 하단 좌표, 캔과 비겹침, 이동·축소 후 체크 배지 없이 완료 |
| 중복 클릭 | 진행도 증가 없음 | 해결 라벨 유지 |
| 완료 | 3/3 후 외출 버튼 활성화 | 완료 배너와 문 강조 |
| 결과/재시작 | 결과 노출, 재시작 0/3 | 결과 요약과 새 게임 화면 |
| 키보드 | Tab/Enter/Space 전체 완료 | 포커스 링과 잘림 없음 |
| 모바일 | 터치 프로필 전체 완료 | 가로 스크롤·겹침·잘림 없음 |

## 탐색 시나리오

1. 부탄캔 미션에서 실내·천공 오답을 연속 선택한 뒤 안전 경로로 복구한다.
2. 미션을 열었다 닫은 뒤 진행도가 보존되는지 확인한다.
