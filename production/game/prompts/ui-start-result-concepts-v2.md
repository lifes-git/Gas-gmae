# Start and result screen concepts v2

작성일: 2026-09-03
도구: OpenAI built-in image generation
상태: 인터뷰용 콘셉트, 런타임 미적용

## 공통 방향

- 기존 화면의 큰 하늘색·라임 그라데이션 판과 반복 점 장식을 제거한다.
- 실제 거실과 야외 배경이 충분히 보이도록 하고, 전경 UI는 하나의 크림 카드로 제한한다.
- 3px 네이비 외곽선, 얕은 하단 그림자, 노랑 주요 버튼과 하늘색 보조 버튼을 사용한다.
- 사용자 제공 레퍼런스에서는 조밀한 정보 위계와 눌리는 버튼 문법만 참고하며 캐릭터·아이콘·배치를 복제하지 않는다.

## 시작 화면 프롬프트 요약

기존 거실 배경과 여행가방을 든 노란 강아지를 유지한다. 강아지는 화면 왼쪽 약 30%, 크림 제목 카드는 오른쪽 약 38%에 배치한다. 제목은 `장기 외출 전`, `가스안전 점검!`, 버튼은 `시작`, `안전수칙`만 표시한다. 하나의 카드만 사용하고 거대한 색상 프레임, 과도한 점 장식, 다중 테두리와 안전 소품 묘사는 금지한다.

## 완료 화면 프롬프트 요약

기존 야외 배경과 배낭을 멘 노란 강아지를 유지한다. 크림 완료 카드에 `3/3`, `안전하게 외출했어요!`, `밸브 잠금`, `수건 이동`, `잔여가스 제거`, `다시하기`, `수칙 보기`만 표시한다. 세 항목은 체크 아이콘과 한 줄 타일로 구성하고 닫기 버튼과 외부 그라데이션 판은 사용하지 않는다.

## 검수

- 불꽃, 폭발, 천공 및 안전 상태를 오해시킬 상세 소품 없음
- 로고와 워터마크 없음
- HTML/CSS로 재현 가능한 단순한 패널 구조
- 한글은 콘셉트 확인용이며 실제 구현에서는 HTML 텍스트 사용
