## 인터뷰에서 확정한 흐름

`거실 바닥 확대 → 부탄캔 집기 → 한 칸 손 슬롯 → 거실 복귀 → 현관문 → 탁 트인 실외 → 캔 회전 → 노즐 길게 누르기 → 안전 이유 → 방으로 돌아가기`

- 수건과 부탄캔은 같은 `현재 들고 있는 물건` 한 칸을 사용한다.
- 물건을 든 동안 다른 위험요소와 방 이동을 잠근다.
- 가방 보관으로 오해할 수 있는 표현은 사용하지 않는다.
