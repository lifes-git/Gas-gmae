# 소멍이 가스안전 웹게임 디자인 시스템 v2.1

## 통합 상호작용 UI — 2026-09-02 인터뷰 최종 승인

이 절은 기존의 웹사이트형 모달, 어두운 자막바, 상시 대형 버튼 규칙보다 우선한다. 안전 행동과 승인 문구는 변경하지 않는다.

- 위험요소 선택 시 현재 방을 어둡게 유지하고 중앙 약 90% 크기의 16:9 확대 장면을 띄운다. 확대 장면에는 얇은 테두리와 우측 상단 닫기만 둔다.
- 조작 대상은 점선 원으로 표시한다. 직접 조작을 기본으로 하며 키보드 입력을 감지하거나 두 번 실패했을 때만 말풍선 옆에 `버튼으로 실행` 대안을 표시한다.
- 소멍이는 확대 장면 왼쪽 아래, 장면 높이의 약 18~22%로 배치한다. 오른쪽 크림색 말풍선은 최대 두 줄을 원칙으로 하며 안내·실수·성공 문구가 같은 자리에서 교체된다.
- 실수는 코랄 얇은 테두리와 `다시 생각해 봐요`, 성공은 초록 얇은 테두리와 체크 및 성공 포즈로 전달한다. 색상만으로 상태를 전달하지 않는다.
- 물건을 줍기 전 닫으면 원래 방으로 돌아간다. 수건·부탄캔을 주우면 확대 화면이 자동으로 닫힌다. 부탄캔을 든 채 실외 확대 화면을 닫으면 물건을 유지한 상태로 거실로 돌아온다.
- 상단 왼쪽에는 작은 `안전 점검 n/3`, 오른쪽에는 설정 아이콘만 둔다. 전체화면, 효과음, 진동, 처음부터 다시하기는 설정 안에 둔다.
- 시작·안전수칙·완료 화면은 크림색 안내판, 소멍이 말풍선, 코랄/하늘색 버튼 체계를 공유한다. 완료 화면은 실외 배경 위에서 소멍이가 완료를 말하고 점검한 세 행동을 다시 보여준다.
- 잡은 물건은 하단 중앙의 한 칸 아이콘 슬롯에 글자 없이 표시한다. 슬롯이 비면 숨기며, 수건을 들면 왼쪽 화살표와 바구니만, 부탄캔을 들면 좌상향 화살표와 현관문만 활성화한다. 자세한 현재 상태와 다음 행동은 `aria-label` 및 소멍이 안내로 유지한다.
- 부탄캔 운반 목적지는 별도 `문밖으로 이동` 글자 버튼으로 덮지 않는다. 실제 현관문 전체 윤곽에 맞는 투명 버튼을 사용하고, 활성 상태에는 흰색 문 윤곽과 바깥쪽 화살표 배지만 표시한다.

## 메모 UI 전환 — 2026-09-02 사용자 승인

이 절은 아래의 이전 색상·타이포·컴포넌트 규칙과 충돌할 경우 우선한다. 안전 행동, 게임 상태, 장면 좌표계는 변경하지 않는다.

- 방향: 집 안에 붙인 점검 메모. 모든 요소를 포스트잇으로 만들지 않고 역할에 맞춰 같은 색과 선을 공유한다.
- 종이 `#fffbe9`, 잉크 `#263c48`, 강조 밑줄 `#f4d563`. 버튼은 사용자 추가 승인한 색종이 스티커 스타일: 주요 코랄 `#ff947b`/글자 `#43271f`/아래 모서리 `#d97660`, 보조 하늘색 `#ade0f4`/글자 `#213e50`/아래 모서리 `#70aec9`.
- 시작 버튼에 재생 삼각형, 안전수칙 버튼에 체크리스트를 코드 SVG로 표시한다. 장식 아이콘은 aria-hidden 처리하고 실제 버튼 텍스트를 유지한다. 강한 광택·두꺼운 흰 테두리 없이 3px 아래 그림자, 누르면 2px 내려가며 그림자가 1px로 줄어든다. 현재 시작 화면의 두 버튼에만 반영했다.
- 글자에 두꺼운 흰색 테두리·입체 그림자를 사용하지 않는다. 본문 400~500, 제목·버튼 600~700. 폰트는 기존 사용 가능 자원만 유지한다.
- 버튼은 12px 둥근 모서리, 얇은 테두리, 낮은 그림자, 최소 44px 터치 높이. 눌림은 2px, 포커스는 3px 잉크색 외곽선. 정오답은 색뿐 아니라 문구·아이콘 병행.
- 시작·안전수칙·결과는 종이 계열 패널, 안내는 간결한 종이 말풍선. 진행도·가방은 소형 표식/슬롯으로 구성한다. 테이프와 종이 기울기는 주요 패널에만 제한한다. 글자와 버튼은 수평 유지.
- 탐색 원은 승인된 얇은 형광 선·은은한 그라데이션 빛·독립 반짝임 유지. 상세 조작은 점선 원. 이번 전환에서 변경하지 않는다.
- 레이아웃: 이미지의 뷰포트 기준 고정 너비가 옆 열을 압축하지 않도록 minmax(0, ...) 열과 max-width:100% 사용. 제목 두 줄과 버튼이 메모 밖으로 나가지 않아야 한다. 모바일 가로 진입 정책 유지.
- 단계: 시작 레이아웃 → 공통 버튼 → 안내/미션 → 가방/진행 → 결과. 단계별 사용자 검수 후 진행.
- 이번 구현: 시작 화면만. 시각 검수 및 실기기 테스트는 사용자 담당으로 미실시. 전체 UI 전환 완료로 간주하지 않는다.
- 후속 구현: 안전수칙 모달도 크림 종이·잉크색 제목·형광펜 밑줄로 전환. 수칙은 하늘색 번호와 얇은 구분선으로 정리하고 코랄 닫기 버튼은 모달 내부에 배치한다. 작은 화면에서는 모달 내부 스크롤, 최소 44px 닫기 목표를 유지한다. 안전 문구와 dialog 동작은 변경하지 않으며 미션·결과 모달은 아직 이전 스타일이다. 사용자 화면 검수 대기.

## 1. 디자인 목표

`따뜻한 생활 공간을 탐색하며 소멍이와 안전 단서를 해결하는 방탈출 게임`을 지향한다. UI는 장면 위에 필요한 순간만 나타나며, 정보를 굵은 사각형 카드로 반복하지 않는다. 반투명 어두운 유리, 얇은 선, 낮은 그림자, 절제된 황동색 강조를 사용한다. 배경과 상호작용 사물이 항상 화면의 중심이다.

## 2. 화면과 안전 구역

- 게임은 브라우저 뷰포트의 가로·세로를 모두 채운다. 바깥 여백, 테두리, 둥근 외곽 프레임을 두지 않는다.
- 메인 장면은 1280×720 고정 `scene-world` 좌표계를 사용한다. 통합 배경·해결 상태 마스크·hotspot·장면 속 효과를 모두 그 자식으로 두고 개별 위치를 화면 크기에 따라 다시 계산하지 않는다.
- 모든 화면에서는 `scene-world` 전체가 보이도록 동일 비율로 확대한다. 확대율은 `min(viewportWidth / 1280, viewportHeight / 720)`로 계산하고 남는 영역은 동일 배경의 어두운 블러 레이어로 채운다.
- HUD·진행도·소멍이 안내는 `scene-world` 밖의 화면 UI 레이어에 두어 장면 확대와 잘림의 영향을 받지 않는다.
- 핵심 HUD, 소멍이, 위험요소는 중앙 90%×84%의 `interaction safe zone` 안에 둔다.
- 전체화면 버튼을 제공한다. 사용자 제스처 후 Fullscreen API를 요청하고 지원 환경에서는 가로 화면 잠금을 시도한다.
- 모바일 세로 화면에서는 게임을 진행시키지 않고 회전 안내를 표시한다. 가로 전환 즉시 원래 상태로 복귀한다.
- 최소 지원 가로 화면은 640×360이며 모든 조작 목표는 44×44 CSS px 이상이다.
- 568×300 미만의 가로 화면에서는 게임 입력을 막고 전체화면 또는 창 확대 안내를 표시한다.

## 4. 타이포그래피

- 시스템 한글 글꼴을 사용하고 외부 폰트를 내려받지 않는다.
- 화면 제목은 700, 버튼과 인벤토리 이름은 600, 본문은 400~500을 사용한다. 800~900 굵기는 사용하지 않는다.
- HUD 제목은 화면 짧은 변 기준 `clamp(15px, 1.6vmin, 23px)`.
- 본문 최소 14px, 주요 조작 버튼 최소 16px.
- 한 말풍선에는 한 행동만 쓰며 최대 두 줄을 원칙으로 한다.

## 5. 컴포넌트

### 공간 결합 원칙

- 핵심 법칙은 `배경 속 사물은 평소에는 실제 공간의 일부로 보이고, 플레이어가 접근한 순간에만 조작 가능성이 드러난다`이다.
- 외형과 기능을 일치시킨다. 회전할 수 있어 보이는 손잡이는 회전하고, 집은 물건은 현장에서 사라져 소지품 슬롯으로 이동하며, 열린 문은 실제 장면 이동을 수행한다.
- 상호작용 사물을 별도의 카드·상시 원·상시 이름표로 감싸지 않는다. 투명 클릭 영역은 사물 실루엣에 가깝게 두되 최소 44×44px 입력 범위는 유지한다.
- 메인 탐색의 위험요소는 배경과 같은 원화에서 함께 제작한다. 완료 상태는 동일한 구도·광원의 대응 장면을 사물 주변의 부드러운 타원 마스크로만 드러내며 직사각형 경계를 금지한다.
- 장식물은 hover·focus를 제외한 포인터 입력에 반응하지 않는다. 조작 가능한 사물만 접근 시 밝기와 얇은 윤곽이 변한다.

### 공통 상호작용 상태

| 상태 | 화면 표현 | 입력과 피드백 |
|---|---|---|
| `ambient` | 사물이 배경에 붙어 보이고 스토리보드형 황금 정원과 별빛이 천천히 반짝임 | 이름표 없음 |
| `discover` | hover 또는 키보드 focus 시 황금 원과 별빛이 한 단계 밝아짐 | 선택하면 해당 위치 기준 최대 1.07배 줌 |
| `active` | 확대 장면에서 사물 외형이 가능한 조작을 암시 | 직접 조작과 동등한 버튼 대안 제공 |
| `solved` | 실제 안전한 배치·상태로 교체 | 초록 체크·별빛을 한 번 표시하고 원과 함께 제거 |

상태 변화의 공통 문법은 `관찰 → 사물 선택 → 외형이 암시한 방식으로 조작 → 즉시 공간 상태 변화 → 안전 이유 확인`이다.

### HUD

- 화면 전체를 가로지르는 바를 사용하지 않는다.
- 좌측 상단의 작은 유리 패널에는 현재 장면명과 행동 목표만 둔다.
- 우측 상단의 별도 작은 패널에는 `0/3~3/3`, 진행 원, 전체화면 버튼을 둔다.
- 테두리는 흰색 22% 투명도의 1px, 모서리는 6~8px, 그림자는 낮게 사용한다.

### 소멍이와 자막

- 소멍이는 좌측 하단의 안내 초상처럼 사용하되 가로 화면에서 약 88~128px를 확보한다.
- 흰색 말풍선과 꼬리를 제거하고 반투명 어두운 한 줄 자막바를 사용한다.
- 자막은 최소 16px 이상으로 한 행동만 최대 두 줄 표시한다. 안내 영역은 화면 왼쪽 46% 이내에 두어 중앙 아래의 부탄캔 hotspot과 겹치지 않는다. 상세 설명은 `ⓘ 안전수칙`으로 분리한다.

### 탐색 신호

- 메인 탐색 화면은 위험요소가 포함된 완성 배경을 사용하고 실제 입력은 같은 1280×720 좌표의 투명 HTML hotspot이 담당한다. 위험요소와 배경의 원근·광원·질감은 한 원화 안에서 고정한다.
- 발견 전에는 클릭 영역 비율과 무관한 1:1 정원형 신호를 사용한다. 2px 안팎의 얇은 형광 황금 실선 뒤에 투명한 방사형 그라데이션 광륜을 두고 2.4초 이상 주기로 은은하게 밝기가 변한다.
- 메인 탐색의 `찾을 대상`은 형광 실선, 클릭 후 확대 장면의 `직접 조작 대상`은 스토리보드처럼 형광 점선 원으로 구분한다.
- hover·터치 접근 시 원의 밝기와 사물 주변 광량만 한 단계 높이고, 키보드 focus에서는 접근성을 위한 파란 윤곽을 함께 표시한다.
- 12초 무입력 시 화면에 원·이름표를 띄우지 않고 소멍이가 아직 해결하지 않은 사물의 위치 방향을 한 문장으로 말한다.
- 해결 후에는 대응 장면을 각 사물 위치의 부드러운 방사형 마스크로 드러낸다. 밸브는 잠김 상태로 바뀌고 수건과 부탄캔은 사라진다. 초록 체크와 별빛은 약 0.9초 동안 한 번 반짝인 뒤 원과 함께 사라진다. 안전 검수 전 임시 밸브 에셋은 `prototype`으로 기록한다.
- 상태 조합별 전체 화면을 만들지 않는다. `위험요소 포함 장면 1장 + 해결 상태 장면 1장 + CSS 마스크 3개`만 사용하므로 세 미션의 자유 순서를 유지하면서도 경우의 수가 늘지 않는다.
- 장식물을 눌렀을 때는 반응하지 않는다.

### 인벤토리

- 화면 하단 중앙에 한 칸짜리 소지품 슬롯을 둔다. 빈 슬롯은 표시하지 않는다.
- 가방·손바닥 이모지와 보유 상태 문구는 사용하지 않는다. 아이템 이미지를 크게 보여 주고, 다음 목적지는 작은 방향 화살표 배지로 전달한다.
- 수건은 왼쪽 바구니, 부탄캔은 좌상단 현관문을 가리킨다. 화면에 숨긴 전체 안내를 슬롯의 `aria-label`에 제공하고 같은 내용을 소멍이의 상황 안내로도 전달한다.

### 공통 형태

- 정보 상자의 테두리는 기본 1px이며 안전상 중요한 직접 조작 범위만 예외로 한다.
- UI 모서리는 6~10px를 사용하고 큰 알약형 버튼과 16px 이상의 반복 카드 모서리를 피한다.
- 큰 발광, 중첩 그림자, 굵은 흰색 외곽선을 반복하지 않는다.

### 직접 조작 사물

- 잡을 수 있는 사물에는 `grab`, 잡은 동안 `grabbing` 커서를 사용한다.
- 드래그 시작 시 1.04배 확대와 짧은 그림자로 손에 든 느낌을 준다.
- 유효 목표 영역은 노란 점선과 행동 동사를 표시한다.
- 성공하면 목표에 스냅하고 체크를 표시한다.
- 실패하면 위험 행동을 애니메이션으로 완수하지 않고 180ms 안에 원위치로 복귀시킨다.

## 6. 미션 상호작용

### 가스밸브

- 같은 밸브 본체 위에서 손잡이만 0→90도로 회전한다.
- 70도 이상 도달하면 90도로 스냅해 완료한다.
- 열린/잠긴 상태를 텍스트로 병기한다.
- 최종 밸브 방향은 Safety Reviewer 승인 전까지 프로토타입 상태다.

### 화기 주변 수건

- 수건을 화기에서 떨어진 `안전 보관 바구니`로 드래그한다.
- 다른 위치에서 놓으면 불이 켜지거나 타는 연출 없이 원위치로 돌아간다.

### 다 쓴 부탄캔

- 방탈출 게임의 인벤토리 문법을 사용하되 밀폐 보관으로 오해할 수 있는 가방 아이콘은 사용하지 않는다.
- 1단계: 거실 바닥의 캔을 선택하면 바닥 확대 모달이 열린다. 확대된 캔을 집으면 모달이 자동으로 닫히고 거실로 돌아오며, 하단 한 칸 슬롯에 빨간 부탄캔 이미지와 현관문 방향 배지만 표시된다.
- 수건과 부탄캔은 같은 한 칸 손 슬롯을 사용한다. 물건을 든 동안 다른 위험요소와 방 이동을 잠그고, 수건은 바구니만, 부탄캔은 현관문만 활성화한다.
- 출입문 너머에는 다음 단계와 동일한 실외 배경을 표시하고 `문밖의 통풍이 잘되는 곳`이라고 명시한다.
- 2단계: 거실에서 현관문을 선택하면 탁 트인 외부 통로·마당 장면으로 전환한다. 캔을 직접 회전해 거꾸로 세운 뒤 노즐을 0.9초간 누른다.
- 처리 완료 후 부탄캔은 현재 들고 있는 물건 슬롯에서 제거된다.
- 완료 직후 자동 복귀하지 않는다. 안전 이유를 확인하고 `방으로 돌아가기`를 선택하면 거실로 복귀한다.
- 부탄캔 미션 동안 `발견 → 집기 → 실외 이동 → 잔여가스 제거` 추적표를 확대 장면 상단에 계속 표시한다. 색뿐 아니라 원·현재 점·체크와 단계명을 함께 사용한다.
- 누르는 동안 원형 진행 표시를 사용한다. 가스 구름, 폭발, 송곳은 표현하지 않는다.

## 7. 대체 조작과 접근성

- 키보드 입력을 감지하거나 직접 조작이 두 번 실패하면 `조작이 어려운가요?` 대체 버튼 영역을 자동 표시한다.
- 모든 직접 조작은 버튼으로 같은 결과를 수행할 수 있다.
- 대체 버튼은 위험한 오답을 실행하지 않고 안전한 행동만 수행한다.
- 포커스는 4px 파랑 외곽선으로 표시한다.
- `aria-live`로 성공, 실패, 회전 안내, 전체화면 상태를 알린다.
- `prefers-reduced-motion`에서는 줌, 펄스, 스냅 이동을 즉시 상태 변경으로 대체한다.

## 8. 모션

- 장면 전환: 300ms 이하, 최대 1.07배.
- 드래그 스냅백: 180ms.
- 성공 체크: 240ms 단발.
- 반복 펄스는 1.4초 이상이며 밝기 급변을 금지한다.
- 화면 흔들림, 강한 블러, 과도한 패럴랙스를 사용하지 않는다.

## 9. 완료 조건

- 배경이 모든 가로 뷰포트를 빈틈 없이 채운다.
- 모바일 세로에서 회전 안내 외의 게임 입력이 차단된다.
- 마우스·터치 직접 조작과 키보드 대체 조작으로 각각 전체 완료할 수 있다.
- 잘못된 드롭이 위험 행동을 실행하지 않는다.
- 완료 직후 세 안전 행동을 화면에서 다시 확인할 수 있다.

## 10. 가로 집중 탐색 UI 개정 — 2026-09-02 사용자 승인

이 절은 위의 황금 원·점선 조작 원·장면 이동 글자 버튼 규칙보다 우선한다.

- 탐색 장면 원본은 `contain` 방식으로 화면 안에 온전히 맞추고 중앙을 유지한다. 초광폭 화면에서도 장면 위·아래를 잘라 확대하지 않는다.
- 화면 비율 차이로 장면 밖에 남는 위·아래 또는 좌우 영역은 현재 거실·주방 장면을 확대한 저채도 블러로 채운다. 따라서 양옆이 단색 빈 공간으로 보이지 않는다.
- `거실로`, `주방으로` 글자 버튼은 화면 가장자리의 `←`, `→` 화살표로 교체한다. 터치 영역은 고정하고 화살표 그림만 해당 방향으로 천천히 왕복한다. 접근 가능한 이름과 키보드 포커스는 유지한다.
- 탐색 및 집기 확대 화면의 원형·점선 표시는 제거한다. 조작 가능한 수건·부탄캔·밸브 소품 실루엣에 얇은 흰색 외곽선을 표시한다.
- 수건과 부탄캔은 hover·focus에서 2~3도 기울이고 약 1.03배 확대한다. 밸브는 열린·잠긴 방향 오해를 막기 위해 회전시키지 않고 약 1.035배 확대만 적용한다.
- 부탄캔을 거꾸로 세우는 처리 단계에는 탐색용 기울기 모션을 적용하지 않는다. 완료한 소품의 탐색 외곽선은 제거한다.
- `prefers-reduced-motion`에서는 화살표 왕복과 소품 기울기를 제거하되 외곽선과 포커스 표시를 유지한다.
- HUD는 별 아이콘과 `n/3`, 설정 아이콘만 보이게 하고 안내 말풍선은 한 행동의 짧은 문구를 우선한다. 상세 안전 문구는 미션 성공 안내, 안전수칙 화면과 접근성 안내에 보존한다.
- 데스크톱 확대 모달은 화면 높이의 약 72% 이하로 제한하고 내부 카메라 범위를 넓혀 대상과 주변 맥락이 함께 보이게 한다. 작은 모바일 가로 화면에서는 조작성 확보를 위해 최대 약 86%까지 허용한다.

## 11. 가로 채움·직접 회전 UI 재개정 — 2026-09-02 사용자 승인

이 절은 10절의 `contain` 및 좌우 블러 여백 규칙보다 우선한다.

- 탐색 장면은 뷰포트 가로폭을 항상 채운다. 비율 차이는 위·아래에서만 균등하게 잘라내며 좌우에 장면 밖 영역을 만들지 않는다.
- 장면 이동은 짙은 외곽선과 하이라이트가 있는 코드 기반 굵은 곡선 화살표를 사용한다. 오른쪽 이동은 코랄, 왼쪽 이동은 하늘색이며 입력 영역은 고정한다.
- 조작 가능한 수건·밸브·부탄캔에는 중앙형 흰색 실루엣 외곽선을 유지한다. hover·focus 기울기는 물체 상태를 오해시키지 않는 범위에서만 적용한다.
- 밸브 확대 화면은 아래쪽 손잡이 끝을 직접 왼쪽으로 드래그해 0도에서 90도까지 회전시키고 성공 후 가로 상태를 유지한다. 회전 방향은 굵은 곡선 화살표로 보여준다. 키보드 및 2회 실패 대체 버튼은 유지한다.
- 야외 부탄캔 화면은 배경을 중심으로 두고 상단 좌측에 숫자·체크만 있는 4단계 표시를 둔다. 캔은 가로 상태에서 시작해 직접 돌려 세우며, 이후 노즐 위치에 누르기 아이콘을 표시한다.
- 야외 완료 후 복귀 컨트롤은 화면 글자 없이 되돌림 아이콘만 표시하고 `방으로 돌아가기` 접근성 이름은 유지한다.
- `prefers-reduced-motion`은 반복 애니메이션만 제거한다. 밸브 잠금과 부탄캔 세우기처럼 상태를 전달하는 최종 회전값은 제거하지 않는다.
- 밸브의 정확한 잠금 방향 표현은 Safety Reviewer 승인 전까지 프로토타입 상태다.

## 12. 출구·소멍이 힌트·완료 상태 개정 — 2026-09-03 사용자 승인

- `hidden` 상태의 현관 입력 영역은 어떤 장면 CSS보다 우선해 표시되지 않는다. 주방에는 현관 윤곽이나 출구 아이콘을 만들지 않는다.
- 주방에서 마지막 위험요소를 해결하면 왼쪽 장면 이동 화살표를 유지한다. 거실로 이동한 뒤에만 현관문 전체가 외출 입력 영역이 된다.
- 부탄캔의 4칸 숫자·체크 단계 UI는 제거한다. 소멍이 말풍선이 현재 행동 하나만 짧게 안내하고 행동 직후 다음 힌트로 교체한다.
- 야외 완료 화면의 복귀 입력 영역은 원화 속 열린 현관문에 맞춘다. 흰색 문 윤곽과 하늘색 진입 화살표만 표시하며 별도 하단 버튼은 사용하지 않는다.
- 수건 완료 후 주방 바구니의 입구 영역 안에 축소·클리핑한 수건 상태를 합성한다.
- 밸브 손잡이가 아래를 향한 시작 상태에서는 손잡이 끝을 왼쪽으로 미는 제스처가 최종 가로 상태와 일치하도록 입력량을 계산한다. 방향 화살표도 왼쪽을 가리킨다.
- 배경음악은 시작 전 자동재생하지 않는다. 시작 후 낮은 음량으로 반복하고, 설정 해제나 탭 비활성화 시 일시정지한다.

## 13. UI 가독성·시작/완료 화면 개정 — 2026-09-03 사용자 승인

- 확대 화면의 복귀는 긴 글자 버튼 대신 우하단 64px 하늘색 곡선 화살표 버튼을 사용한다. 화면 글자는 없지만 한국어 접근성 이름은 유지한다.
- 확대 화면 소멍이와 말풍선은 좌하단에서 약간 위로 올리고, 복귀 버튼과 수평으로 겹치지 않도록 최대 폭을 제한한다.
- 조작 가능한 소품의 흰색 실루엣 외곽선은 기존보다 약 2px 굵게 보강한다. hover 기울기와 완료 후 상태 제거 규칙은 유지한다.
- 진행 카드와 설정 버튼은 데스크톱에서 각각 최소 높이 62px, 52px로 확대한다. 작은 모바일 가로 화면에서는 46px, 44px로 축소해 장면을 가리지 않는다.
- 시작·완료 화면은 크림색 내부 패널, 짙은 4px 외곽선, 하늘색·라임 프레임, 코랄·하늘색 눌림 버튼을 공유한다. 레퍼런스의 시각 문법만 참고하고 원본 그래픽은 복제하지 않는다.
- 완료 항목은 긴 목록 대신 세 개의 동일한 완료 타일로 표시해 중앙 집중 구도와 빠른 확인을 우선한다.

## 14. UI 컴포넌트 시스템 — 2026-09-03 사용자 승인

- `ui-components.css`가 팔레트, 외곽선, 모서리, 그림자 깊이와 버튼 상태의 단일 원본이다. 장면별 위치와 특수 연출은 `toon-ui.css`에 남긴다.
- 버튼 변형은 `primary` 노랑, `info` 하늘색, `success` 라임, `danger` 코랄, `neutral` 크림으로 제한한다.
- 정적 버튼은 `data-ui-component`와 `data-ui-variant`, 동적 버튼은 `GameUI.createButton()`으로 같은 클래스와 상태 규칙을 적용한다.
- 아이콘 버튼은 `data-ui-icon` 또는 `iconOnly`를 사용하며 한국어 `aria-label`을 필수로 한다.
- 진행 HUD, 말풍선, 시작·완료 패널과 모달은 각각 `.ui-progress`, `.ui-speech`, `.ui-panel`, `.ui-modal` 공통 표면 클래스를 사용한다.
- hover는 최대 1.5도 기울기, active는 3px 눌림, focus는 4px 흰색 외곽선을 사용한다. 모션 감소 환경에서는 상태 변형을 제거한다.

## 15. 시작·완료 화면 테마 확정 — 2026-09-03 사용자 승인

이 절은 13절의 시작·완료 화면 패널 규칙보다 우선한다.

- 게임 정체성은 소방 출동이 아니라 `장기 외출 전 가스안전 점검`으로 고정한다.
- 사용자 레퍼런스는 캐릭터·로고·구도가 아니라 두꺼운 외곽선의 입체 제목과 눌림감 있는 플라크 버튼의 시각 문법만 참고한다.
- 시작 화면은 거실 배경과 여행가방을 든 소멍이를 그대로 노출하고, 큰 전면 카드 없이 크림·노랑 입체 제목과 노랑 `시작`, 하늘색 `안전수칙` 버튼을 배치한다.
- 완료 화면은 야외 배경과 열린 현관문을 그대로 노출하고 `안전점검 완료!`, `3/3`, 세 개의 체크 배지, 노랑 `다시하기`, 하늘색 `수칙 보기`를 배치한다.
- 소방관, 출동대, 사이렌, 불꽃과 같은 긴급출동 이미지는 사용하지 않는다.
- 제목과 버튼 글자는 이미지에 굽지 않고 HTML 텍스트와 CSS 컴포넌트로 렌더링한다.
