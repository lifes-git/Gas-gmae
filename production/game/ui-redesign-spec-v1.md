# 웹게임 UI 개편 명세 v1

작성일: 2026-08-31  
상태: 사용자 인터뷰 승인 / 프로토타입 반영

## 화면 원칙

- 기본 화면은 16:9 고정 게임 스테이지이며, 배경 장면이 화면 대부분을 차지한다.
- 상단에는 좌측 장면명과 우측 `0/3~3/3` 진행 원만 표시한다. 타이머는 사용하지 않는다.
- 소멍이는 좌측 하단에 배치하고 짧은 한 문장 말풍선으로 안내한다.
- 위험요소는 자유 순서로 선택한다. 처음에는 노란 강조 원만 표시하고 12초 무입력 후 이름 힌트를 표시한다.
- 내부 안전수칙 ID와 제작용 단계 코드는 사용자 화면에 노출하지 않는다.

## 장면 전환과 미션

- 위험요소 선택 시 해당 위치를 기준으로 `1.07배 / 300ms` 이내의 완만한 줌을 적용한 뒤 전체 확대 장면으로 교체한다.
- `prefers-reduced-motion`에서는 줌과 장면 진입 애니메이션을 생략한다.
- 직접 조작 의미를 가진 큰 행동 버튼을 기본으로 제공하고, 같은 버튼으로 터치·마우스·키보드를 모두 지원한다.
- 미션 우측 상단에는 언제든 나갈 수 있는 닫기 버튼을 둔다.
- 성공 후 자동 복귀하지 않는다. 성공 문구, 상세 설명 토글, `방으로 돌아가기` 버튼을 제공한다.
- `왜 안전한가요?`를 누르면 같은 말풍선 안에서 승인된 안전 설명을 펼친다.

## 반응형

- 데스크톱과 가로 화면은 16:9 스테이지 안에서 모든 HUD와 조작을 오버레이한다.
- 세로 화면은 `상단 HUD → 축소된 16:9 장면 → 소멍이 말풍선/조작` 순으로 재배치한다.
- 세로 화면에서 핵심 장면을 잘라 채우지 않는다. 현재 390×844 프로필에서 정상 동작하므로 가로 전용 차단은 사용하지 않는다.

## 시작과 완료

- 시작 화면은 열린 현관 배경과 외출 포즈 소멍이로 `장기간 외출 전 점검` 상황을 먼저 설명한다.
- 완료 화면은 같은 현관 배경과 소멍이 중심의 전체 일러스트 화면으로 구성한다.
- 완료 문구는 `외출 준비 완료!`, 버튼은 `다시하기`, `수칙 다시보기`로 한다.
