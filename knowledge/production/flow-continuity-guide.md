# Flow 연속성 가이드

공식 참조 사용법: https://support.google.com/flow/answer/16353334?hl=en

## 고정 자산

- 인물: 정면·측면, 의상, 연령대, 머리, 특징
- 장소: 구조, 시간대, 조명, 색상 팔레트
- 소품: 가스기기, 밸브 등 안전 의미를 갖는 물체의 형태와 위치
- 상태: 장면 전후의 문·밸브·창문·불꽃·의상 상태

각 요소에 고유 이름을 붙이고 모든 프롬프트에서 같은 이름과 사양을 사용한다. 참조 이미지는 배경을 단순화하고 스타일을 통일한다.

## 샷 원칙

- 한 클립에 핵심 행동 하나
- 주체, 행동, 장소, 카메라, 조명, 스타일, 오디오, 타이밍 순으로 기술
- 텍스트와 참조 이미지가 충돌하지 않게 함
- 전후 샷의 상태를 기록하고 필요하면 마지막 프레임을 다음 샷 기준으로 사용
- 손, 가스기기, 밸브, 불꽃 오류는 후편집으로 숨기지 말고 재생성
- 정확한 안전 문구는 생성 음성만 믿지 않고 별도 오디오·자막으로 검수

## 기록

장면 번호, 모델, 길이, 프롬프트, 참조 자산, 생성일, 사용 크레딧, 채택 여부와 이유를 기록한다.
