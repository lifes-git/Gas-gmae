# 가스안전 챌린지 게임 GDD v0.3

작성일: 2026-08-31
상태: G2 초안 / G3a 조건부 검토

## 콘셉트

장기간 집을 비우기 전, 플레이어는 `가스킷`과 함께 거실·주방이 한눈에 보이는 집 안에서 세 개의 가스안전 위험요소를 찾는다. 위험요소를 클릭하면 확대 화면이 열리고 안전 행동을 수행한다. 세 개를 모두 해결하면 현관문이 열리고 외출에 성공한다.

## 전체 흐름

```text
타이틀 → 조작 안내 → 집 안 탐색 0/3
  ├─ 밸브 미션
  ├─ 화기 주변 수건 미션
  └─ 다 쓴 부탄캔 미션
→ 3/3 집 안 반짝임 → 현관문 클릭 → 외출 성공 → 다시하기
```

미션 순서는 자유다. 위험요소는 기본 상태에서 공간의 일부처럼 보이고, 접근할 때만 미세한 밝기·윤곽 변화로 조작 가능성을 알린다. 해결 후에는 가능한 경우 실제 안전한 상태나 위치로 교체하며 체크는 보조 정보로만 사용한다.

## 메인 탐색 화면

- 16:9 풀스크린 게임 스테이지를 사용하고 별도 웹사이트형 사이드바는 두지 않는다.
- 통합 배경·해결 상태 마스크·hotspot은 1280×720 고정 월드 안에서 `FIT` 방식으로 함께 확대·이동한다. 화면 비율별 hotspot 좌표 보정은 하지 않는다.
- HUD와 소멍이 안내는 고정 월드 밖의 화면 UI 레이어에 둔다.
- 상단 왼쪽: 현재 장면명 `탐색 · 위험요소를 찾아보세요!`
- 상단 오른쪽: 세 개 진행 원 `○○○`
- 중앙: 원안과 같은 거실·주방 통합 장면이 화면 대부분을 차지한다.
- 위험요소 위치: 주방 가스밸브, 화기 가까운 수건, 바닥의 다 쓴 부탄캔
- 좌측 하단 소멍이 말풍선: `장기간 외출 전, 집 안의 위험요소 3개를 찾아보세요!`
- 위험요소에는 스토리보드와 연결되는 얇은 황동색 원을 사용한다. 원은 약하고 느리게 반짝이며 사물은 배경과 한 원화에서 제작해 공간에 결합한다.
- 12초 무입력 후에는 화면 표식을 추가하지 않고 소멍이가 아직 해결하지 않은 사물의 위치 방향을 한 문장으로 안내한다.
- hover에서는 원과 사물 주변 광량이 조금 강해진다. 완료 시 동일 구도의 해결 장면을 부드러운 국소 마스크로 드러내고 초록 원과 체크를 사용한다. 반복 반짝임은 멈추며 장식물은 눌러도 반응하지 않는다.
- 키보드 사용자는 장면 버튼과 동일한 접근 가능한 위험요소 목록을 사용할 수 있다.

위험요소 선택 시 해당 위치를 기준으로 약한 줌인 후 전체 확대 미션 장면으로 교체한다. 성공 후에는 자동 복귀하지 않고 플레이어가 `방으로 돌아가기`를 선택한다.

### 공통 상호작용 상태

```text
ambient(배경의 일부) → discover(접근 반응) → active(확대·직접 조작) → solved(공간 상태 교체)
```

- `ambient`: 원·펄스·이름표 없음
- `discover`: hover 밝기 변화, 키보드 focus 윤곽, 선택 시 최대 1.07배 줌
- `active`: 사물 외형과 조작 방식 일치, 버튼 대안 제공
- `solved`: 수건은 안전 보관 위치, 부탄캔은 현장에서 제거, 밸브는 검수된 잠김 에셋으로 교체

## Mission 1 — 가스밸브 잠그기

- 제목: `밸브를 클릭!`
- 상황: `장기간 외출하기 전 가스밸브를 확인해요.`
- 조작: 밸브 확대 → 잠금 버튼 또는 90도 회전 제스처
- 성공: `좋아요! 장기간 외출 전 가스밸브를 잠갔어요.`
- 제한: 실제 밸브 기준으로 열린/잠긴 상태가 승인되기 전에는 `열림`, `잠김` 텍스트 placeholder 사용
- 수칙: `GS-OUTING-01`

## Mission 2 — 화기 주변 수건 옮기기

- 제목: `가스레인지 주변을 클릭!`
- 상황: 가스레인지는 꺼진 상태이며 수건이 화기 가까이에 놓여 있다.
- 조작: 수건을 화기와 떨어진 지정 보관 바구니로 드래그하거나 `안전한 곳으로 옮기기` 버튼 선택
- 성공: `종이, 수건, 부탄캔은 화기 주변에 두지 않아요.`
- 금지: 수건을 쓰레기통에 버리기, 불이 켜진 상태, 수건에 불이 붙는 연출
- 수칙: `GS-FIRE-01`

## Mission 3 — 다 쓴 부탄캔 안전 처리

- 제목: `다 쓴 부탄캔을 클릭!`
- 1단계 질문: `잔여가스는 어디에서 제거해야 할까요?`
  - 정답: `통풍이 잘되는 실외 장소`
  - 오답: `주방 안`, `쓰레기봉투 안`
- 2단계 조작: 실외 배경으로 전환한 뒤 부탄캔을 거꾸로 들고 노즐을 누르는 순서를 선택
- 성공: `통풍이 잘되는 곳에서 잔여가스를 완전히 제거한 뒤 지역 분리배출 기준을 확인해요.`
- 필수 경고: `잔여가스 제거 전에 구멍을 뚫지 않아요.`
- 금지: 송곳 도구, 실내 가스 배출, 폭발·중독 장면, 지역과 무관한 단일 배출함 단정
- 수칙: `GS-BUTANE-DISPOSAL-01`
- 별도의 단계 추적표는 표시하지 않는다. 소멍이 말풍선이 현재 필요한 한 행동만 `집기 → 현관문 → 캔 회전 → 노즐 길게 누르기` 순서로 안내한다.

## 완료와 외출

- 세 요소 완료: `모든 위험요소를 해결했어요! 이제 안전하게 외출해요.`
- 현관문에 활성화 테두리 표시
- 문 클릭 후 캐릭터가 문밖으로 이동
- 결과: `외출 성공! 오늘도 가스안전 지킴이!`
- 버튼: `다시하기`, `수칙 다시보기`

## 상태 모델

```text
GameState = intro | room | mission | readyToExit | result
Hazard = valve | towel | butane
HazardState = unsolved | active | solved

readyToExit = hazards.every(solved)
```

중복 클릭은 진행도를 추가하지 않는다. Mission 3은 `실외 선택`과 `잔여가스 제거 순서`를 모두 완료해야 해결된다.

## 접근성과 반응형

- 1280×720 기준, 터치 목표 최소 44×44 CSS px
- 모든 hotspot은 실제 HTML 버튼과 동기화
- Tab/Enter/Space로 전체 완료, 드래그는 버튼 대안 제공
- 진행 상태를 색뿐 아니라 체크·숫자·텍스트로 표시
- 시간 제한 없이 진행하며 `aria-live` 피드백과 reduced-motion을 지원
- 세로 화면은 상단 HUD, 축소된 16:9 장면, 소멍이 말풍선과 조작 버튼 순으로 배치
- 모션 감소 설정에서는 줌 전환을 생략
- 모바일 세로 화면은 게임 입력을 차단하고 가로 회전 안내를 표시한다.
- 키보드 입력 감지 또는 직접 조작 2회 실패 시 승인된 안전 행동 대체 버튼을 표시한다.

## 직접 조작

- 밸브: 아래쪽 손잡이 끝을 왼쪽으로 밀어 90도 가로 상태로 스냅
- 수건: 화기에서 떨어진 안전 보관 바구니로 드래그
- 부탄캔 1단계: 부탄캔을 클릭해 글자 없는 한 칸 아이콘 슬롯에 넣은 뒤, 방향 배지와 소멍이 안내를 따라 기존 실외 배경이 보이는 출입문을 클릭
- 부탄캔 2단계: 실외에서 손바닥 슬롯의 부탄캔을 다시 선택하면 캔과 노즐 조작이 나타남
- 부탄캔 2단계: 실외에서 강조된 노즐을 0.9초간 누르기
- 잘못된 드롭은 위험 행동을 실행하지 않고 원위치 복귀와 안전 안내만 제공

시각·모션·상태·화면 안전 구역의 단일 기준은 `production/game/design.md`를 따른다.

## 플레이테스트 과제

1. 설명 없이 세 hotspot을 모두 찾아 임의 순서로 해결
2. 수건을 쓰레기통 쪽으로 드래그했을 때 안전한 보관 위치를 안내하는지 확인
3. 부탄캔 미션에서 실내를 선택했을 때 위험 행동이 실행되지 않는지 확인
4. 키보드만으로 전체 완료
5. 종료 직후 기억한 세 안전 행동과 위험한 오기억 기록

## 탐색 표현 개정 — 2026-09-02

- 16:9 장면은 화면 안에 온전히 들어오는 `contain` 중앙 정렬을 사용한다. 남는 위·아래 또는 좌우 영역은 같은 장면의 블러로 채워 단색 빈 공간을 만들지 않는다.
- 방 이동은 글자 버튼 대신 고정된 좌우 가장자리 화살표를 사용하고, 화살표 그림만 천천히 좌우로 왕복한다.
- 위험요소와 집기 대상의 원형 표시는 제거하고 소품 실루엣을 따르는 흰색 외곽선으로 교체한다.
- 수건·부탄캔은 hover·focus 시 2~3도 기울기, 밸브는 안전 상태 보존을 위해 확대만 적용한다.
- 화면 문구는 별 `n/3`, 짧은 행동 안내, 짧은 완료 항목을 우선하며 전체 안전 설명은 수칙 화면과 접근성 안내에 유지한다.
- 데스크톱 미션 모달은 화면 높이 약 72% 이하로 제한하고 밸브·수건·부탄캔 주변을 더 넓게 보여준다.

## 탐색·회전 상호작용 재개정 — 2026-09-02

- 탐색 장면은 가로폭을 빈틈없이 채우며 비율 차이는 위·아래에서만 중앙 크롭한다.
- 좌우 이동은 코랄·하늘색의 굵은 곡선 화살표로 표시하고 버튼의 접근성 이름은 유지한다.
- 세 위험요소의 흰색 실루엣 외곽선을 복원한다.
- 밸브는 직접 드래그하는 동안 0–90도로 회전하고 완료 후 손잡이를 가로 상태로 유지한다. 그래픽 화살표로 방향을 안내한다.
- 야외 부탄캔은 `발견–집기–실외 이동–잔여가스 제거`를 숫자·체크 4칸으로 표시하고, 캔 회전 후 노즐 길게 누르기를 단계적으로 연다.
- 야외 복귀는 화면 글자 없는 되돌림 아이콘을 사용하되 스크린리더 이름과 키보드 조작은 보존한다.
- 밸브 방향은 안전 추적표 승인 전 프로토타입으로 취급한다.

## 장면 출구·힌트·음향 개정 — 2026-09-03

- 현관 출구는 거실에만 존재한다. 주방에서 3/3을 달성하면 거실 이동 화살표를 유지하고, 거실에 돌아온 뒤 현관문을 선택한다.
- 야외 부탄캔의 숫자 단계 HUD를 제거하고 소멍이가 매 순간 다음 한 행동만 말풍선으로 알려준다.
- 야외 완료 후 복귀는 배경 속 열린 현관문 전체를 선택하며, 하단 별도 복귀 버튼은 표시하지 않는다.
- 수건 완료 상태는 주방 왼쪽 바구니 안에 실제 수건이 보이도록 유지한다.
- 밸브는 아래쪽 손잡이 끝의 실제 궤적에 맞춰 왼쪽 드래그로 90도 회전한다. 최종 잠금 방향의 안전 승인은 별도다.
- 배경음악은 시작 버튼이라는 사용자 제스처 뒤 16% 음량으로 반복 재생하고 설정의 `음악·효과음` 토글로 일괄 음소거한다.

## 시작·완료 화면 테마 개정 — 2026-09-03

- 시작과 완료 화면은 소방 출동 서사가 아니라 장기 외출 전 안전점검의 시작과 완료를 표현한다.
- 시작 화면은 큰 카드 없이 거실 배경, 여행가방을 든 소멍이, 입체 제목, 두 개의 플라크 버튼으로 구성한다.
- 완료 화면은 야외 배경, 배낭을 멘 소멍이, `안전점검 완료!`, `3/3`, 세 안전 행동 체크 배지와 두 개의 후속 버튼으로 구성한다.
- 레퍼런스는 제목 글자와 버튼 테마만 참고하며 원본 캐릭터·로고·레이아웃은 복제하지 않는다.
