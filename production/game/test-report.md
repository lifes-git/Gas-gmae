## 이번 테스트에서 수정된 결함

- 완료 현관문의 위치 이동 애니메이션 때문에 클릭 대상이 안정되지 않던 문제를 그림자 펄스로 변경했다.
- 재시작 뒤 해결 완료 `aria-label`이 남던 문제를 기본 라벨 저장·복원 방식으로 수정했다.
- 결과 제목이 포커스를 받을 수 있도록 `tabindex=-1`을 추가했다.
- E2E가 미션 순서와 모달 닫힘 애니메이션에 의존하던 문제를 제거했다.
- 사용자 결정에 따라 타이머 UI와 관련 상태·테스트를 제거했다.

### 가로 집중 탐색·소품 외곽선 회귀 — 2026-09-02

- 1672×941 장면을 화면 안에 온전히 맞추는 중앙 `contain` 방식으로 변경했다. 위·아래 또는 좌우에 남는 영역은 현재 방 원화를 확대한 저채도 블러로 채우며 모달 뒤 배경에도 7px 블러를 적용했다.

- 메인 탐색과 집기 확대 화면의 점선 원을 제거하고 수건·밸브·부탄캔 소품 알파 실루엣에 흰색 외곽선을 적용했다.
- 수건 hover 상태에서 계산된 transform이 활성화되는 것을 검사하고 `qa/screenshots/desktop-kitchen-towel-hover.png`로 시각 확인했다. 밸브는 회전 효과에서 제외했다.
- HUD는 별과 `n/3`, 결과 점검표는 `밸브 잠금`, `수건 이동`, `잔여가스 제거`로 축약했다. 상세 안전 문구와 `aria-label`은 유지했다.
- Chromium 1440×900 마우스 전체 흐름, 1280×720 키보드 전용 흐름, 390×844 회전 안내, 844×390 터치 흐름과 집기 취소·소지 상태 복구를 재통과했다.

### 초광폭 중앙 구도·모달 배율 수정 — 2026-09-02

- 사용자 캡처와 유사한 1920×945 콘텐츠 영역에서 거실·주방 16:9 원본이 잘리지 않고 수평·수직 중앙에 놓이는지 경계 좌표로 검사했다.
- 좌우 영역은 단색 여백이 아니라 현재 장면의 저채도 블러로 채워지는 것을 의사 요소의 배경 이미지로 확인했다.
- 수건·밸브·부탄캔 외곽선의 다중 방향 `drop-shadow`를 단일 중심 그림자로 단순화해 GPU 필터 경계에 생기던 오른쪽 세로선을 제거했다. 원본 PNG 우측 8px의 알파 픽셀은 0개임을 별도로 확인했다.
- 데스크톱 모달을 화면 높이 최대 72%로 줄이고 밸브·수건·부탄캔 `viewBox`를 넓혀 주변 공간을 함께 보이게 했다. 1920×945 캡처에서 모달 높이가 화면의 74% 이하인지 자동 검사했다.
- 이전 모달의 늦은 `close` 이벤트가 다음 모달의 키보드 대체 버튼을 숨기던 포커스 경합을 수정했다. 이후 데스크톱 마우스, 키보드 전용, 모바일 터치, 취소·소지 복구 전체 회귀를 연속 2회 통과했다.
