# 에셋 배치 v2 — 안전 소품 생성 기록

도구: built-in `image_gen`  
생성일: 2026-08-31

## 공통 잠금

- 배경 마스터의 2D 교육용 게임 화풍, 진한 갈색 외곽선, 부드러운 셀 셰이딩을 유지한다.
- 교체 상태는 같은 소품 마스터를 재사용한다.
- 이미지에 글자·로고·브랜드·경고문을 넣지 않는다.
- 투명 PNG는 `file` 검사에서 RGBA가 확인된 결과만 채택한다.
- 불꽃, 가스 구름, 폭발, 송곳, 천공, 화상 표현은 만들지 않는다.

## 수건·바구니

- `prop-towel-folded-v1`: 민트색의 깨끗하게 접힌 면 수건. 불탄 흔적·오염·무늬 없음.
- `prop-basket-empty-v1`: 낮은 직사각형 우븐 보관 바구니. 쓰레기통으로 보이는 뚜껑·표식 없음.
- 위험 위치·이동·보관 완료는 두 마스터의 좌표와 레이어만 변경해 표현한다.

## 밸브

- 세로 배관과 황동 볼밸브, 노란 레버 한 개로 한정했다.
- 열린 초안: 노란 손잡이가 세로 배관과 평행.
- 잠긴 초안: 노란 손잡이가 배관과 수직이 되도록 90도 회전.
- 생성된 잠긴 초안은 열린 초안과 캔버스·본체 형상이 달라 `revise`다. 구현 시 열린 마스터의 손잡이만 코드 또는 정밀 편집으로 회전한다.
- 실제 게임에는 `열림`, `잠김` HTML 라벨을 함께 둔다.

## 부탄캔

- `prop-butane-used-v1`: 브랜드와 글자 없는 온전한 적·은색 휴대용 부탄캔, 노즐이 보이는 상태.
- 실내 발견은 수평 배치, 실외 처리 단계는 동일 이미지를 CSS로 뒤집어 상태 연속성을 보장한다.
- 노즐 누르기는 HTML 강조점과 선택 버튼으로 표현하고 가스 분사·연기·구멍은 그리지 않는다.
