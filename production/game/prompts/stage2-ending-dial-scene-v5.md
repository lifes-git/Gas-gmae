## 최종 프롬프트

`illustration-story` 용도의 Stage 2 엔딩 두 번째 16:9 컷. 기존 저녁 야외 배경, 파란 휴대폰, 소멍이의 두 앞발과 한국 플래시게임풍 선화·색감을 참조하되 전체 장면을 하나의 일러스트로 다시 그린다. 휴대폰 화면에는 표준 순서의 `1 2 3 / 4 5 6 / 7 8 9 / * 0 #` 원형 번호 패드와 하단 초록색 통화 버튼을 표시한다. 한 손가락이 번호를 자연스럽게 누른다. 화면 요소는 휴대폰 유리의 원근, 조명, 반사와 일치해야 한다. 특정 전화번호·연락처·브랜드·진동선·수신 표시·워터마크는 넣지 않는다. 덧댄 사각 패널이나 서로 다른 그림체가 보이지 않아야 한다.

## 선택 이유

휴대폰 화면만 합성한 v4에서 발생한 경계, 손가락 가림, 원근 불일치를 제거하기 위해 휴대폰·손·번호 패드를 한 장면으로 재생성했다.
