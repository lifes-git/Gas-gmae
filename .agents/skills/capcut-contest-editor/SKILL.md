# CapCut Contest Editor

Read `knowledge/production/capcut-workflow.md`, official rules, and the asset license log. For a film, also read the approved script and shot list. For a game, read the product brief, GDD, approved gameplay build, and capture plan.

## Choose the track

- Film: follow the narrative editing passes below.
- Game: capture only the approved real build at 1080p or higher. Show title and goal, representative touch or pointer interaction, immediate educational feedback, progression, and result within about one minute. Do not fake unavailable gameplay with concept art or imply features absent from the build. Keep pointer visibility and safety copy readable.

## Qualify the tool

Before the main edit, create a 20-second test with three Flow clips, Korean text, an external licensed audio file, and one basic transition. Export 1080p MP4. Stop if CapCut requests payment, adds branding, corrupts text, or cannot play smoothly; remove premium elements or switch to the approved fallback.

## Edit in passes

1. Assembly: clips only, correct story order.
2. Rough cut: reach 55–58 seconds before the end card.
3. Dialogue and narration: ensure every safety phrase is exact.
4. Sound: add effects and licensed external music; keep speech intelligible.
5. Text: one message per screen, high contrast, mobile-readable.
6. Polish: basic cuts and short dissolves, consistent color and loudness.
7. End card: safe action, campaign phrase, required attribution if approved.

## Audit and export

Inspect every timeline element for Pro status and license evidence. Do not use CapCut built-in music by default. Export 1080p MP4, then watch the exported file from start to finish on speakers and headphones. Check runtime, black frames, artifacts, subtitle spelling, loudness jumps, branding, and sync.
