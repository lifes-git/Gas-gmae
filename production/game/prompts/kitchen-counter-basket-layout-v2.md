## 생성 지시

precise-object-edit: 원본의 따뜻하고 선명한 2D 그림체, 복숭아색 타일, 크림 상부장, 네이비 하부장, 목재 조리대, 정면 시점 유지. 같은 빈 바구니를 왼쪽 아래 수납칸에서 왼쪽 조리대 위로 이동(약 화면 폭 20%). 바닥 접촉 그림자와 열린 입구, 수건 없음. 기존 수납칸 비우기. 꺼진 레인지를 조금 오른쪽(중심 약 68%)으로 옮기고 후드도 그 위에 정렬. 오른쪽 배관과 손잡이 없는 허브 유지. 바구니와 레인지 사이 넓은 빈 조리대. 캐릭터, UI, 글자, 화살표, 수건, 캔, 불꽃 추가 금지. 배치 시안이며 안전 최종 승인 아님.

## 검토

바구니는 조리대 위로 이동했고 기존 칸은 비워짐. 후드와 레인지도 오른쪽으로 이동. 생성 결과에서 배관 위치도 소폭 이동했으므로 적용 시 기존 손잡이/클릭 좌표 재사용 금지. 신규 좌표·수건 완료 상태·모달 크롭을 함께 맞춰야 함. 기존 원본 및 게임 코드는 보존.
