# 엔딩 제목 PNG 제작 기록

- 목적: 결과 화면에 사용할 정확한 문구 `안전점검 임무 완료!`의 투명 PNG 제작
- 도구: OpenAI image generation
- 기준 에셋: 기존 결과 제목 이미지의 노란 입체 글자, 남색 외곽선, 흰색 스티커 테두리
- 생성 지시: 한글 문구를 정확히 유지하고, 밝고 친근한 캐주얼 웹게임 제목 스티커로 제작. 별과 초록 체크는 작은 보조 장식으로만 사용.
- 수정 지시: 글자·외곽선·장식을 바꾸지 않고 배경만 균일한 크로마 그린으로 교체.
- 후처리: `production/game/scripts/chroma-edge-to-alpha.cjs`로 이미지 가장자리와 연결된 크로마 영역만 투명화. 제목 내부의 초록 체크는 보존.
- 안전 영향: 안전 문구가 아닌 완료 상태 제목. 실제 안전 확보나 수리 완료를 의미하지 않음.
