# 가스안전 챌린지 아트 바이블 v0.2 — 스타일 잠금

작성일: 2026-08-31  
상태: 에셋 제작용 잠금 규격

## 절대 일관성 규칙

아래 항목은 장면마다 재해석하지 않는다. 생성 결과가 하나라도 벗어나면 선택하지 않고 다시 만든다.

1. 모든 실내 배경은 `bg-room-day-master-v1.png`를 스타일·공간·팔레트·조명의 기준 이미지로 사용한다.
2. 모든 소멍이 포즈는 `mascot-somyeongi-guide-v1.png`와 사용자가 제공한 소멍이 레퍼런스 3장을 외형 기준으로 사용한다.
3. 같은 집의 벽은 크림색, 바닥은 밝은 오크, 창밖은 맑은 낮, 포인트는 네이비·옅은 하늘색으로 고정한다.
4. 카메라 높이, 약한 3/4 원근, 둥근 외곽선, 부드러운 셀 셰이딩을 유지한다. 장면별로 실사·3D·수채화·애니메이션풍을 섞지 않는다.
5. 배경에는 교체 가능한 위험 소품, 캐릭터, 글자, 로고, hotspot 효과를 합성하지 않는다.
6. 캐릭터의 얼굴형, 귀 크기, 눈 간격, 눈썹, 볼터치, 몸 색, 2등신 비율을 바꾸지 않는다.
7. 안전 상태만 바뀌는 소품은 같은 카메라·크기·피벗을 유지하며 상태 파일끼리 정렬 가능해야 한다.
8. 새로운 색은 기존 팔레트의 명도·채도 범위를 벗어나지 않는다. 위험 표시용 빨강은 UI에서만 제한적으로 쓴다.
9. 이미지 내부에는 어떤 언어의 글자도 만들지 않는다.
10. 최종 선택 전 썸네일 크기, 모바일 crop, 연속 배치 비교를 모두 통과해야 한다.

## 방향

- 밝고 친근한 2D 교육용 웹게임 일러스트
- 원안의 `한 공간 탐색 + 노란 hotspot + 강아지 안내자` DNA를 유지한다.
- 개발 프로토타입에서는 한국가스안전공사의 웹툰 캐릭터 `소멍이`를 임시 기준 캐릭터로 사용한다. 최종 제출 전 공식 활용·AI 변형 허용 범위를 다시 확인하며, 필요하면 동일 역할의 독자 캐릭터로 교체한다.
- 이미지 안에 글자·로고·워터마크를 넣지 않는다. 모든 안내 문구는 HTML로 렌더링한다.
- 공포·폭발·불붙은 천·유독가스 연출은 사용하지 않는다.

## 금지 드리프트

- 소멍이의 얼굴·귀·체형이 장면마다 다른 캐릭터처럼 변하는 현상
- 공식 원본이 아닌 AI 생성 KGS 로고를 최종 제출물에 확정 적용하는 행위
- 생성 이미지 속 한글·영문·숫자, 의류 로고, 워터마크
- 밸브 열린/잠긴 방향을 검수 없이 확정한 그림
- 켜진 가스불, 수건 소각/폐기, 실내 부탄가스 배출, 송곳 천공
- 배경에 hotspot용 소품을 합쳐 상태 교체가 불가능하게 만드는 구성

## 1차 생성 순서

1. `mascot-somyeongi-guide`: 소멍이 기반 프로토타입 안내 포즈, 투명 배경
2. `bg-room-day`: 소품을 제외한 거실·주방 통합 배경
3. 캐릭터 표정 변형 4종
4. 안전 소품: 스토브(꺼짐), 수건, 부탄캔, 밸브 — 별도 안전 검수 후 확정

## 출력 규격

- 마스코트 마스터: 투명 PNG, 정사각형, 최소 1024×1024
- 배경 마스터: 불투명 PNG/WebP 원본, 16:9, 최소 1536×1024 계열
- 런타임: 배경 WebP 약 500KB 이하 목표, 투명 소품 WebP/PNG
- 파일명은 소문자 kebab-case와 상태 접미사를 사용한다.

## 레퍼런스 기반 UI 보강 — 2026-09-02

- 사용자 제공 레퍼런스의 굵은 짙은 외곽선, 코랄·하늘색·라임 포인트, 눌리는 하단 그림자 문법만 참고하며 아이콘·배치·캐릭터는 복제하지 않는다.
- 탐색 가능한 소품은 별도 원을 두르지 않고 투명 PNG/SVG 알파 실루엣을 따라 2px 안팎의 흰색 외곽선을 표시한다.
- 래스터 소품 외곽선은 여러 방향의 `drop-shadow`를 연속 중첩하지 않는다. 단일 중심 그림자를 사용해 GPU 필터 경계의 직선 아티팩트를 방지한다.
- 수건과 부탄캔은 선택 전 hover·focus에서 2~3도만 기울인다. 밸브는 안전 상태를 나타내는 각도를 장식 모션으로 변경하지 않는다.
- 장면 이동 화살표의 입력 상자는 고정하며 내부 화살표만 7px 이내로 왕복한다.
- 보유 물건 UI는 한 칸 노란 슬롯에 기존 투명 소품 이미지를 크게 배치하고, 작은 하늘색 방향 배지만 덧붙인다. 이름·상태·행동 문구는 화면에 쓰지 않으며 접근성 이름으로 보존한다.
- 현관 상호작용은 원화의 문틀 전체에 투명 입력 영역을 맞춘다. 활성 상태는 얇은 흰색 윤곽과 하늘색 바깥쪽 화살표만 사용하며 문을 가리는 글자 패널은 두지 않는다.
- 이 개정은 기존 에셋을 CSS로 표현하므로 새 이미지·폰트·라이선스 항목을 추가하지 않는다.

## 굵은 곡선 화살표·실루엣 보강 — 2026-09-02

- 사용자 레퍼런스에서는 굵은 곡선, 짙은 외곽선, 밝은 면색, 작은 하이라이트라는 시각 문법만 차용한다. 첨부 화살표 이미지는 에셋으로 복제하거나 배포물에 포함하지 않는다.
- 좌우 이동 및 회전 안내 화살표는 프로젝트 안에서 새로 작성한 인라인 SVG 도형으로 구현한다. 이동은 코랄·하늘색, 회전은 코랄로 구분한다.
- 흰색 실루엣 외곽선은 물체 알파 경계를 따라가며 오른쪽 직선 아티팩트가 생기지 않도록 중심 `drop-shadow`만 중첩한다.
- 상태 표현인 밸브·부탄캔 회전은 hover 장식보다 우선한다. 성공 후에도 최종 각도와 소품이 화면에 남아야 한다.
- 이번 변경은 코드 기반 UI와 기존 런타임 소품만 사용하므로 에셋 매니페스트와 라이선스 항목은 추가하지 않는다.

## 완료 상태·배경음악 보강 — 2026-09-03

- 수건 완료 상태는 새 래스터를 만들지 않고 기존 투명 수건을 바구니 입구 영역에 축소·클리핑해 합성한다.
- 야외 복귀는 배경 속 현관문의 형태를 가리지 않는 얇은 흰색 윤곽과 하늘색 화살표만 사용한다.
- `Suitcase_and_Sunlight.mp3`는 사용자가 직접 만든 배경음악으로 제공했으며, 런타임에는 재인코딩 없이 연결한다. 생성 도구·프롬프트 등 공모전 제출용 상세 이력은 최종 승인 전에 보완한다.
- 음악은 대사·힌트를 방해하지 않도록 기본 음량 0.16을 사용한다.

## UI 시각 통일 보강 — 2026-09-03

- 시작·완료 패널은 `#24323b` 4px 외곽선, 크림 내부 카드, 하늘색에서 라임으로 이어지는 외부 프레임, 4~9px 하단 눌림 그림자를 공통 문법으로 사용한다.
- 배경의 작은 점 장식은 CSS로만 생성하고 장면 원화 및 레퍼런스 이미지는 수정·복제하지 않는다.
- 조작 소품 외곽선은 중심 흰색 `drop-shadow` 반경을 4.8px와 3.8px로 중첩해 기존보다 약 2px 두껍게 인식되도록 한다.
- 확대 화면 복귀 아이콘은 하늘색 64px 정사각형 카드와 짙은 곡선 화살표로 제작하며 별도 래스터 에셋을 추가하지 않는다.
