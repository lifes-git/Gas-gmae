## 직접 재사용

- `S02 → S05`: S02 채택본의 안정 프레임
- `S03 → S06`: S03 채택본의 얼굴이 가장 안정적인 보행 프레임
- `S04A → S10`: 동일 시작 이미지
- `S11A/S11B`: 기존 가스레인지 ON/OFF 근접 레퍼런스

## 공통 검수

- 위험 선택 장면: 왼쪽 화구만 작은 파란 불꽃 ON, 오른쪽 화구 OFF.
- 안전 선택 완료 장면: 양쪽 화구 완전 OFF, 잔불 없음.
- 전화 화면은 검정이며 생성 이미지 안에 문자·앱 UI·말풍선이 없음.
- 가족 저녁은 정확히 세 사람·세 의자·세 자리이며 전화가 식탁에 없음.
