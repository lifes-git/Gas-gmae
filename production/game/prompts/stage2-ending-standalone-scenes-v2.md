## 공통 프롬프트 제약

- 한국 플래시 게임풍의 선명한 카툰 일러스트, 굵고 깨끗한 외곽선과 부드러운 셀 셰이딩.
- 저녁 야외 복도와 파란 현관문의 공간·조명·팔레트를 참조 이미지와 연결한다.
- 소멍이의 얼굴·체형·색·흰 스카프와 S 로고를 유지한다.
- 한 이미지에는 한 장면만 넣고 화면 전체를 채운다.
- 이미지 안에는 말풍선, 꼬리, 카드, 명패, 글자, 숫자, 체크 표시, UI, 워터마크를 넣지 않는다.
- CSS 말풍선 또는 결과 카드를 배치하는 장면은 오른쪽 42%를 비운다.

## 장면별 프롬프트

1. `ending-scene-exit-v2`: 열린 파란 현관문에서 안전한 실외로 걸어 나오는 전신 소멍이. 전화기는 들고 있지만 사용 전이며 발밑에 작은 먼지 효과만 둔다.
2. 휴대전화 진동 클로즈업 시안은 발신 흐름과 맞지 않아 폐기했으며, 최종 번호 입력 컷은 `stage2-ending-dial-scene-v5.md`에서 관리한다.
3. `ending-scene-call-v2`: 화면 왼쪽 1/3에서 소멍이가 전화기를 귀에 대고 전문가에게 통화한다. 오른쪽 42%는 CSS 말풍선용 배경만 남긴다.
4. `ending-scene-complete-v2`: 화면 왼쪽 1/3에서 소멍이가 통화를 마치고 전화기를 내린 채 엄지를 든다. 오른쪽 42%는 CSS 완료 카드용 배경만 남긴다.
