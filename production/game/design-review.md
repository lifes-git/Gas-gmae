## 근거

- `외출 전 위험요소 3개 찾기 → 3/3 → 외출 성공`이라는 핵심 루프와 12컷 구조를 유지했다.
- 세 미션을 모두 정부·공공기관 공식 자료와 `verified` 수칙에 연결했다.
- 원안에서 문제가 된 송곳 천공만 제거하고 안전한 잔여가스 제거 순서로 교체했다.
- 창문 환기는 적용 상황이 모호해 제외했고, 밸브 잠금과 중복되는 가스불 끄기 대체안도 제외했다.
- 수건 미션은 유지하되 쓰레기통 투척 대신 안전한 보관 위치로 옮기게 했다.

## 조건

1. 화면과 대사에 `장기간 외출`을 명확히 표시한다.
2. 최종 밸브 열린/잠긴 이미지는 Safety Reviewer가 다시 승인한다.
3. 가스레인지는 처음부터 꺼진 상태로 표현하고 수건을 화기에서 떨어진 곳으로 옮긴다.
4. 부탄캔 처리 화면은 반드시 실외/통풍 장소로 전환하고 송곳을 보여주지 않는다.
5. 정책브리핑의 원본 카드뉴스 이미지는 권리 확인 없이 에셋으로 복제하지 않고, 안전 정보만 근거로 사용한다.
