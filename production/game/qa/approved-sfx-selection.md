# 효과음 청취 선택 반영

- 사용자 선택: 버튼 B(가벼운 뽁), 수건 A(포근한 사락, 조금 낮게), 캔 A(낮은 금속 울림).
- sound-preview.js의 파형·음정·필터를 game.js에 반영. 청취 페이지 기본 마스터 0.6 기준, 수건만 추가로 진폭 25% 감소.
- 버튼 tap 및 확대 open에 버튼 B 적용. 캔 획득/뒤집기에 캔 A 적용. 수건 배치는 같은 재질의 짧은 변형.
- 성공 멜로디는 최근 수건/캔 조작음 종료 후 최소 60ms 뒤에 재생.
- 기존 배경음악, 밸브, 이동, 배출음은 유지. 청취 비교 페이지는 원본 비교용으로 유지.
- Node 구문 검사 및 git diff --check 통과. 실제 게임 청취 검수는 미실시.
