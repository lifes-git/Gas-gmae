# 가스안전 챌린지 게임 Product Brief v0.3

작성일: 2026-08-31
상태: 원안 프레임 복원 / G2 검토 대상

## 제품 한 줄 정의

초·중·고등학생이 강아지 안전요원 `가스킷`과 함께 장기간 외출 전 집 안의 가스안전 위험요소 3개를 찾아 해결하는 2~3분짜리 백엔드 없는 터치 웹게임.

## 원안 보존 원칙

- 핵심 제목과 목표: `외출 전 위험요소 3개 찾기`
- 한 공간을 탐색하고 노란 강조 표시가 있는 위험요소를 클릭
- 각 위험요소를 짧은 조작으로 해결하고 1/3~3/3 진행 표시
- 모두 해결하면 현관문을 통해 외출 성공
- 밝은 2D 주거 공간, 강아지 안내 캐릭터, 큰 터치 대상, 즉시 체크 피드백 유지

## 안전상 필요한 최소 변경

- 적용 범위를 `일반 외출`이 아니라 공식 근거가 있는 `장기간 외출`로 명시한다.
- 창문 환기와 켜진 가스불 미션은 제외한다.
- 가연성 천은 쓰레기통에 버리지 않고, 불이 꺼진 상태에서 화기와 떨어진 보관 위치로 옮긴다.
- 부탄캔은 실내에서 처리하지 않는다. 통풍이 잘되는 장소를 선택한 뒤 잔여가스를 제거하며, 제거 전 송곳으로 구멍을 뚫지 않는다.

## 위험요소 3개

1. 장기간 외출 전 열려 있는 가스밸브 잠그기 — `GS-OUTING-01`
2. 화기 주변의 수건을 안전한 위치로 옮기기 — `GS-FIRE-01`
3. 다 쓴 부탄캔을 통풍이 잘되는 장소에서 안전하게 잔여가스 제거 후 지역 기준에 맞게 배출하기 — `GS-BUTANE-DISPOSAL-01`

## 핵심 루프

`방 탐색 → 위험요소 클릭 → 안전 행동 수행 → 이유 확인 → 1/3 진행 → 세 개 완료 → 외출 성공`

## 대상과 환경

- 핵심 대상: 초등 고학년부터 고등학생
- 환경: 터치스크린 TV, 태블릿, PC 웹브라우저
- 최초 플레이 목표: 2분 10초~2분 50초
- 입력: 터치, 마우스, 키보드

## MVP 범위

- 타이틀, 조작 안내, 한 개의 집 내부 탐색 화면
- 세 개 hotspot과 개별 조작 모달
- 정답, 안전한 오답 피드백, 힌트, 0/3~3/3 진행 표시
- 외출 성공, 다시하기, 수칙 다시보기
- 자막, 음소거, 시간 제한 없는 학습 흐름
- 정적 HTML 빌드와 1분 실행영상

## 진행 정책

사용자 결정에 따라 타이머는 제외한다. 플레이어가 관찰과 안전 행동 학습에 집중하도록 시간 제한 없이 진행한다.

## 제외 범위

- 로그인, 서버, 온라인 랭킹, 개인정보 수집, 분석 SDK
- 화재·폭발·중독 재현
- 실내 부탄가스 배출 조작
- 잔여가스 제거 전 부탄캔 천공
- 권리 불명확한 음원·폰트·캐릭터·로고

## 성공 기준

- 설명 없이 첫 hotspot 발견·조작 성공률 80% 이상
- 세 요소 전체 완료율 100%, 중앙 완료시간 2분~2분 40초
- 플레이 직후 세 행동을 모두 정확히 회상하는 비율 80% 이상
- 위험한 오기억 0건
- 터치·마우스·키보드 각각 전체 완료
- 주요 브라우저·모바일 터치 프로필 치명적 오류 0건

## 주요 미해결 위험

- 밸브 열린/잠긴 시각 상태 최종 검수
- 부탄캔 잔여가스 제거 인터랙션이 위험한 모방을 유도하지 않는지 G3b 검수
- 원안 캐릭터와 로고의 권리·AI 생성 이력 확인
- 실제 대상 연령 플레이테스트
