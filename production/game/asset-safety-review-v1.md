# 안전 소품 1차 검토 v1

작성일: 2026-08-31

## 판정

**Revise — 수건·바구니는 Art Go, 밸브와 부탄캔은 안전 장면 합성 전 조건부**

| 에셋 | 판정 | 근거·조건 |
|---|---|---|
| 접힌 수건 | Go | 손상·화염 없이 화기 주변에서 안전 보관 위치로 옮기는 동일 소품으로 사용 가능 |
| 빈 보관 바구니 | Go | 쓰레기통 표식이 없고 수건을 폐기하지 않는 안전 위치로 표현 가능 |
| 밸브 열림 | 조건부 | 특정 세로 배관 볼밸브에서 손잡이 평행 상태를 표현. HTML `열림` 라벨 필수 |
| 밸브 잠김 | Revise | 손잡이는 수직이지만 열린 파일과 본체·캔버스가 달라 회전 애니메이션 연속성이 깨짐 |
| 부탄캔 기본 | 조건부 | 온전한 일반 캔으로 적절. 실내에서 가스가 나오는 표현 금지 |
| 부탄캔 뒤집기 | 조건부 | 열린 실외 배경에서 동일 캔을 회전해 사용. 노즐 누르기 전 장소 선택이 먼저 완료되어야 함 |

## 필수 구현 조건

- 밸브는 한 마스터에서 손잡이만 정확히 90도 회전하고 `열림/잠김` 텍스트를 병기한다.
- 수건 미션의 레인지는 항상 꺼진 상태다.
- 부탄캔은 `통풍이 잘되는 실외 장소 선택 → 거꾸로 들기 → 노즐 누르기` 순서를 지킨다.
- 잔여가스 제거 전에 송곳으로 구멍을 뚫는 장면은 실행하지 않는다.
- 부탄가스 분사, 가스 구름, 폭발·중독 효과는 보여주지 않는다.
