# 메인 탐색 대응 장면 v3

작성일: 2026-09-02  
도구: OpenAI built-in ImageGen  
방식: 기존 장면 정밀 편집

## 채택 구조

- `unsafe`: 같은 집 안에 열림 상태 프로토타입 밸브, 화기 가까운 민트 수건, 바닥의 빨간 부탄캔을 함께 그린 완성 장면.
- `solved`: 같은 구도에서 수건과 부탄캔을 제거하고 가로 손잡이의 잠김 상태 프로토타입 밸브만 남긴 대응 장면.
- 런타임에서는 두 장을 1280×720으로 동일 축소하고 각 위험요소 위치의 CSS 방사형 마스크만 선택적으로 표시한다.

## 공통 생성 지시

- 입력 장면의 카메라, 방 구조, 가구, 가스레인지, 따뜻한 낮 조명, 선 굵기, 채색 질감과 선명도를 최대한 보존.
- 위험요소는 제품 렌더링처럼 과장하지 않고 방의 원근과 크기에 맞게 작게 배치.
- 접지 그림자는 받침 표면에 맞춰 짧고 부드럽게 표현.
- 글자, UI, 발광 원, 캐릭터, 추가 소품을 넣지 않음.
- 밸브 방향은 최종 안전 검수 전까지 시각 프로토타입으로 기록.

## 폐기 결과

- 세 물체를 한 투명 레이어에 요청했으나 가스레인지까지 복제된 결과는 폐기.
- 개별 투명 수건과 부탄캔은 제품 렌더링처럼 지나치게 세밀하고 넓은 광륜이 생겨 폐기.
- v2 독립 스프라이트 방식은 배경과 원근·광원·질감이 일치하지 않아 런타임에서 제거.

## 확대 미션 대응 장면

- 통합 원화의 물체 정체성과 스타일을 기준으로 밸브 벽면, 수건·가스레인지 상판, 부탄캔 바닥을 각각 16:9 고해상도 확대 재구성.
- 조작용 수건·부탄캔·밸브 손잡이는 해당 확대 장면 픽셀에서 마스킹해 배경과 같은 디자인을 유지.
- 조작 배경은 물체가 제거된 대응 장면을 사용해 드래그·회전 중 원래 물체가 이중으로 보이지 않게 함.
- 메인 장면과 미션 배경은 마스터 해상도를 유지한 채 WebP 품질 88로 최적화. 마스터 PNG는 별도 보존.
