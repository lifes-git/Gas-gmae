# 시작·완료 화면 테마 콘셉트 v3

## 목적

- 게임의 정체성은 `장기 외출 전 가스안전 점검`으로 유지한다.
- 사용자 레퍼런스는 캐릭터·로고·구도·전투 분위기가 아니라, 손으로 그린 듯한 제목 글자와 두꺼운 외곽선의 게임 버튼 테마만 참고한다.
- 소방관, 출동대, 화재 진압, 사이렌, 불꽃과 같은 소방·긴급출동 요소는 사용하지 않는다.
- 이번 산출물은 시작 화면과 완료 화면의 시각 콘셉트이며 런타임 코드에는 적용하지 않는다.

## 공통 조형 언어

- 짙은 남색 이중 외곽선, 크림·노랑 글자 면, 짧고 단단한 입체 그림자
- 작은 별과 체크 장식만 제한적으로 사용
- 버튼은 둥근 사각형보다 게임 간판 같은 비대칭 플라크 형태로 구성
- 큰 카드나 반투명 웹 패널 없이 배경 장면을 충분히 노출
- 실제 구현 시 한글은 이미지가 아니라 HTML 텍스트로 재현

## 시작 화면 프롬프트 요약

기존 따뜻한 거실과 여행가방을 든 노란 강아지를 유지한다. 화면 오른쪽 상단에 자유롭게 떠 있는 일러스트 제목 `장기 외출 전`, `가스안전 점검!`을 배치하고, 아래에는 노란색 `시작`, 하늘색 `안전수칙` 플라크 버튼을 세로로 정렬한다. 거대한 전면 카드와 그라데이션 판은 사용하지 않는다.

## 완료 화면 프롬프트 요약

기존 햇살 좋은 야외 통로와 열린 현관문, 배낭을 멘 노란 강아지를 유지한다. `안전점검 완료!`, `안전하게 외출했어요!`를 자유롭게 떠 있는 일러스트 제목으로 구성하고 `3/3` 배지를 둔다. `밸브 잠금`, `수건 이동`, `잔여가스 제거`는 상세 소품 대신 체크 표시가 있는 작은 완료 배지로 표현한다. 하단에는 노란색 `다시하기`, 하늘색 `수칙 보기` 플라크 버튼만 둔다.

## 검수

- 소방·출동·화재 진압 이미지 없음
- 불꽃, 연기, 폭발, 가스용기 및 밸브의 안전 상태를 오해시킬 상세 아이콘 없음
- 외부 로고와 워터마크 없음
- 레퍼런스의 저작물 요소를 직접 복제하지 않고 글자·버튼의 일반적 시각 문법만 참고
- HTML/CSS/SVG 컴포넌트로 재현 가능한 구조
