# 수정 스토리보드 v0.3 — 기존 3요소

원안의 12컷, 한 공간 탐색, 외출 성공 구조를 유지하되 창문 환기와 대체 가스불 미션은 제외한다.

| 컷 | 화면/행동 | 유지·수정 사항 |
|---:|---|---|
| 1 | `위험요소를 찾아보세요!` 집 안 전체, ○○○ | `장기간 외출 전` 문구 추가, 타이머 제외 |
| 2 | `밸브를 클릭!` 확대 화면 | 원안 유지 |
| 3 | 밸브 잠금 성공 | 열린/잠긴 상태 안전 검수 후 사용 |
| 4 | `가스레인지 주변을 클릭!` 수건 강조 | 가스레인지는 꺼진 상태 |
| 5 | 수건을 안전 보관 바구니로 이동 | 쓰레기통에 버리는 연출 수정 |
| 6 | 수건 미션 성공과 이유 표시 | 화기 주변 가연물 수칙 |
| 7 | `다 쓴 부탄캔을 클릭!` | 원안 유지 |
| 8 | 잔여가스를 제거할 장소 선택 | 통풍이 잘되는 실외가 정답 |
| 9 | 거꾸로 들어 노즐 누르기 | 송곳 제거, 지역 배출 기준 확인 추가 |
| 10 | `모든 위험요소 해결 완료!` 집 안 전체 3/3 | 원안의 완료 연출 유지 |
| 11 | 현관문 클릭, 외출 | 원안 유지 |
| 12 | `외출 성공! 오늘도 가스안전 지킴이!` | 원안 유지 |

## 절대 유지할 디자인 DNA

- 한 장면 안에서 위험요소를 먼저 찾는 재미
- 노란 원 hotspot과 큰 손 포인터
- 강아지 캐릭터의 짧은 안내
- 해결 직후 초록 체크와 진행 원 채우기
- 마지막 현관문과 외출 성공 보상

## 레벨 디자인 적용 원칙

- 전체 방 탐색 화면은 스토리보드 1·10·11컷의 허브 역할을 한다.
- 위험요소를 누르면 2–9컷처럼 대상이 크게 보이는 집중 화면으로 전환한다.
- 각 미션은 `발견 → 안전 행동 선택 → 이유 피드백 → 초록 체크` 순서를 유지한다.
- 세 미션은 자유 순서로 선택할 수 있지만 각 미션 내부의 안전 행동 순서는 고정한다.
- 타이머 없이 관찰과 학습에 집중한다.

## 안전 때문에 바뀌는 부분만

- `일반 외출` → `장기간 외출`
- 창문 환기 미션 제외
- 켜진 가스불 미션 제외
- 수건을 쓰레기통에 버리기 → 꺼진 가스레인지에서 떨어진 안전 보관 위치로 이동
- 부탄캔 송곳 천공 → 통풍되는 실외에서 잔여가스 제거 전 천공 금지
