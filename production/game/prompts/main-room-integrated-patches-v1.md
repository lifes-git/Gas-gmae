# Main Room Integrated Exploration Assets v1

생성일: 2026-09-02  
도구: built-in `image_gen`  
용도: 메인 탐색 화면 통합 배경과 해결 상태 국소 패치

## 통합 메인 배경

- 원본 실내 배경의 구도·가구·조명·스타일을 유지한다.
- 제공된 밸브를 가스레인지 근처 타일 벽의 배관에 연결한다.
- 수건을 가스레인지 가까운 조리대 위에 원근과 접지 그림자를 맞춰 놓는다.
- 다 쓴 부탄캔을 주방 쪽 목재 바닥에 원근과 접지 그림자를 맞춰 놓는다.
- UI, 원, 반짝임, 글자, 캐릭터, 로고, 불꽃은 이미지에 포함하지 않는다.

## 밸브 해결 소스

- 통합 배경에서 밸브 손잡이만 90도 회전한 프로토타입 상태를 생성한다.
- 배관, 밸브 본체, 장면의 나머지 요소는 유지한다.
- 안전 검수 전에는 최종 잠김 상태로 승인하지 않는다.

## 수건 해결 소스

- 조리대 위 수건만 제거하고 동일한 조리대 표면과 그림자를 복원한다.
- 밸브, 부탄캔과 나머지 장면은 유지한다.

## 부탄캔 해결 소스

- 바닥의 부탄캔만 제거하고 동일한 바닥 원근·나뭇결·조명을 복원한다.
- 밸브, 수건과 나머지 장면은 유지한다.

## 후처리

- 모든 소스를 1280×720으로 정규화한다.
- 해결 소스는 `production/game/tools/build_local_state_patches.py`로 변경 영역만 남긴 투명 RGBA 패치로 변환한다.
- 패치 경계에는 10px 페더 마스크를 적용한다.
