# 《두 번째 알림은 오지 않게》 간이 스토리보드 v1

목표 길이: 60초 내외  
핵심 안전 행동: 조리 중 자리를 떠나야 한다면 가스불을 먼저 끈다.  
화면 비율: 16:9

## 전체 흐름

`평범한 저녁 준비 → 개인 알림 → 가족에게 번지는 미래 경고 → 완성되지 못한 저녁 → 선택 직전으로 복귀 → 가스불 OFF → 가족의 완성된 저녁`

## 엔드카드 문구

> 알림보다 먼저, 가스불부터.

보조 문구: `조리 중 자리를 뜨기 전, 가스불을 먼저 끄세요.`

## 색과 화면 문법

- 현재 현실: 따뜻한 주방 조명과 자연스러운 생활 색감
- 가능한 미래: 약간 차가운 색온도와 얇은 코랄색 가장자리 맥동
- 안전 행동 이후: 현실의 따뜻한 색감 회복
- 실제 화재, 연기, 폭발, 대피 장면은 보여주지 않는다.
- 휴대전화 UI와 한글은 생성 영상이 아닌 CapCut에서 합성한다.

## 간단 연속성 체크

- 엄마: 크림색 상의, 남색 앞치마, 낮게 묶은 머리
- 아빠: 왼손 검은 업무 가방, 오른손 휴대전화
- 딸: 남색 백팩을 양쪽 어깨에 착용, 오른손 휴대전화
- 가스레인지: 왼쪽 화구와 냄비만 사용, 오른쪽 화구는 계속 OFF
- 미래 이전에는 불꽃 ON, 안전 행동 뒤에는 양쪽 화구가 완전히 OFF
- 처음 식탁은 미완성, 마지막 식탁만 완성된 가족 저녁
