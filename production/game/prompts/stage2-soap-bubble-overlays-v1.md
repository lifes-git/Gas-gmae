# Stage 2 비눗물 점검 효과 오버레이 v1

- 생성일: 2026-09-11
- 도구: Codex built-in `image_gen`
- 용도: 배관 연결부 점검 결과를 나타내는 투명 PNG 효과
- 참고 이미지: Stage 2 통합 배관 PNG(그림체), 사용자 제공 스토리보드(거품 밀도와 진행 흐름)

## 정상 오버레이

플래시게임풍의 둥근 실루엣으로 얇고 낮은 유백색 거품 띠와 소수의 작은 거품만 분리된 에셋으로 생성한다. 배관·붓·손·문자·숫자·아이콘·배경은 포함하지 않는다. 프로젝트의 친근한 2D 셀 셰이딩과 굵은 청록 외곽선을 유지하며, 유리구슬처럼 사실적인 광택은 피한다. 후처리를 위해 바깥 영역은 균일한 크로마 그린으로 생성한다.

## 누출 의심 오버레이

연결부 한 지점에서 빠르게 쌓이는 플래시게임풍의 불규칙한 고밀도 거품 더미를 분리된 에셋으로 생성한다. 정상 상태보다 높고 넓은 실루엣, 큰 유백색 거품과 작은 위성 거품을 함께 사용한다. 굵은 청록 외곽선과 단순한 셀 셰이딩을 적용하며 폭발·불꽃·가스 연기·공포 표현은 넣지 않는다. 배관·붓·손·문자·숫자·아이콘·배경은 포함하지 않는다. 후처리를 위해 바깥 영역은 균일한 크로마 그린으로 생성한다.

## 후처리

- `chroma-key-to-alpha.cjs`로 크로마 그린을 실제 알파로 변환하고 투명 경계를 트리밍했다.
- 런타임 파일은 표시 크기에 맞게 축소하고 팔레트 PNG로 최적화했다.
- CSS는 이미지의 위치와 등장 확대, 누출 의심 상태의 미세한 호흡, 가장자리에서 작은 방울이 간헐적으로 솟는 모션만 담당한다.
