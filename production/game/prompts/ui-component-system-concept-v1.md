# UI component system concept v1

작성일: 2026-09-03
도구: OpenAI built-in image generation
용도: 구현 전 UI 디자인 방향 인터뷰용 콘셉트 시트

## 기준

- 사용자 제공 모바일 게임 UI 레퍼런스 2장에서는 굵은 짙은 외곽선, 밝은 면색, 짧은 하단 그림자, 아이콘 중심 구성만 참고했다.
- 현재 게임 화면 캡처에서는 크림·노랑·코랄·하늘색·라임 팔레트와 소멍이의 친근한 교육 분위기만 유지했다.
- 레퍼런스의 캐릭터, 아이콘, 배치, 브랜드 요소는 복제하지 않았다.
- 안전 소품의 실제 상태나 밸브 방향을 확정하는 이미지가 아니라 UI 외형을 비교하는 시안이다.

## 1차 생성 프롬프트 요약

16:9 가로형 고충실도 UI 컴포넌트 시트. 기본·호버·눌림 버튼, 복귀·닫기·설정·좌우 화살표, 별과 2/3 진행 HUD, 인벤토리 슬롯, 소멍이 말풍선, 16:9 모달 프레임, 시작 카드, 세 칸 완료 카드를 한 장에 배치한다. `#24323B`, `#FFF9DF`, `#FFD95A`, `#FF8291`, `#55D3EF`, `#9CDE28` 팔레트와 굵은 외곽선, 둥근 모서리, 눌림 그림자를 사용한다. 화면 글자는 최소화하고 색만으로 의미를 전달하지 않는다. 로고·워터마크·불꽃·폭발·천공 표현을 금지한다.

## 교정 프롬프트

1차 결과의 인벤토리 속 빨간 부탄캔에 생성된 흰색 불꽃 기호만 제거하고, 빈 캔 식별을 뜻하는 작은 흰색 체크로 교체했다. 그 외 배치, 글자, 색, 캐릭터, 그림자와 테두리는 유지했다.

## 선정 이유

- 버튼의 기본·호버·눌림 상태가 한눈에 비교된다.
- 아이콘 버튼, 진행 HUD, 인벤토리, 말풍선, 모달, 시작·완료 화면이 같은 디자인 언어로 묶인다.
- HTML/CSS/SVG 컴포넌트로 옮기기 쉬운 단순한 형태다.

## 상태

`concept-only`: 사용자 인터뷰와 컴포넌트 규격 확정 전에는 런타임 에셋으로 사용하지 않는다.
