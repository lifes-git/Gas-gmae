# 형광 윤곽·사운드·타이틀 복귀

- 수건/밸브: 기존 SVG 외곽 마스크를 얇게 하고 Gaussian blur를 배후에 합성, 흰 형광 윤곽+은은한 확산광. 원본 픽셀 변경 없음.
- 자체 Web Audio 사인파 효과음: 확대 열기 1음, 집기 상승 2음, 장면 이동 2음, 완료 3음, 전체 외출 성공 4음, 오류 하강 2음, 설정 1음. 외부 음원/유료 소재 없음. 기존 소리 설정을 따르고 음악 요소를 재생성하지 않음.
- 다시하기: 진행 초기화 후 타이틀 표시, 시작 버튼 포커스. 게임으로 즉시 재진입하지 않음.
- 음악: preload auto/autoplay와 초기 play 시도. 재생 중에는 play 재호출 생략, currentTime 초기화 코드 제거. 자동재생 차단 시 첫 pointer/key 입력에서 재시도. 페이지 숨김 및 음소거에서는 기존 정지 정책 유지.
- 검증: game.js/kitchen-scenes.js Node 구문 검사 및 git diff --check 통과. 실제 청음, 브라우저 정책별 재생, 모바일 회귀 테스트는 미실시.
